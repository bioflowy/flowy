    - ValidateToken(secret, tokenString) returns Claims struct with UserID, Username, Role on valid token
    - ValidateToken returns error on expired, malformed, or wrong-secret tokens
    - HashPassword(password, cost) returns a bcrypt hash
    - CheckPassword(hash, password) returns nil on match, error on mismatch
    - ResolveJWTSecret(cfg, store) returns configured secret or auto-generates and persists one

   - Define context key type and `UserClaimsKey` constant for middleware context injection.
   - `IssueToken(secret []byte, userID, username, role string) (string, error)` — creates JWT with HS256, 7-day expiry, sub=userID, username and role as custom claims.

   - `CheckPassword(hash, password string) error` — wraps `bcrypt.CompareHashAndPassword`.
   - `ResolveJWTSecret(ctx context.Context, jwtSecretCfg string, st Store) ([]byte, error)` — where `Store` is a minimal interface with `GetServerConfig`/`SetServerConfig` (avoid importing full store package). If `jwtSecretCfg` is non-empty, return it as bytes. Otherwise check DB for "jwt_secret" key. If not found, generate 32 random bytes, hex-encode, persist via SetServerConfig, return.
   - Use `DefaultBcryptCost = 12` constant; accept cost as parameter in HashPassword for test flexibility.

1. Restructure `newRouter()` in `internal/server/server.go` to use three conditional route groups:

   ```go
   func (s *Server) newRouter() *chi.Mux {
       r := chi.NewRouter()
       r.Use(middleware.Logger)
       r.Use(middleware.Recoverer)

       // Default 404/405 (keep existing)
       r.NotFound(...)
       r.MethodNotAllowed(...)

       // Public routes — always available regardless of auth.enabled
       r.Get("/health", s.handleHealth)
       r.Post("/auth/login", s.handleLogin)

       if s.cfg.Auth.Enabled {
           // User-authenticated routes (JWT middleware)
           r.Group(func(r chi.Router) {
               r.Use(JWTMiddleware(s.jwtSecret))

               // Workflow routes (existing)
               r.Post("/workflows", s.handleSubmit)
               r.Get("/workflows/{id}/status", s.handleStatus)
               r.Get("/workflows/{id}/outputs", s.handleOutputs)
               r.Post("/workflows/{id}/abort", s.handleAbort)

               // User management routes
               r.Get("/users/me", s.handleGetMe)
               r.Put("/users/me/password", s.handleChangePassword)
               r.With(roleRequired("admin")).Post("/users", s.handleCreateUser)
               r.With(roleRequired("admin")).Get("/users", s.handleListUsers)
               r.With(roleRequired("admin")).Delete("/users/{id}", s.handleDeleteUser)
           })

           // Daemon-authenticated routes (pre-shared token)
           r.Group(func(r chi.Router) {
               r.Use(DaemonAuthMiddleware(s.cfg.Auth.DaemonToken))
               r.Post("/tasks/run", s.handleTaskRun)
               r.Post("/tasks/claim", s.handleClaim)
               r.Post("/tasks/{id}/result", s.handleResult)
               r.Post("/heartbeat", s.handleHeartbeat)
           })
       } else {
           // Auth disabled: flat registration with no middleware (current behavior preserved)
           r.Post("/workflows", s.handleSubmit)
           r.Get("/workflows/{id}/status", s.handleStatus)
           r.Get("/workflows/{id}/outputs", s.handleOutputs)
           r.Post("/workflows/{id}/abort", s.handleAbort)

           r.Post("/tasks/run", s.handleTaskRun)
           r.Post("/tasks/claim", s.handleClaim)
           r.Post("/tasks/{id}/result", s.handleResult)
           r.Post("/heartbeat", s.handleHeartbeat)
       }
       return r
   }
   ```

The `/auth/login` route is always registered (it returns 401 "auth not enabled" when auth is disabled — or simply remains available as a no-op public route).
