<task type="auto" tdd="true">
  <name>Task 2: Add bearer token injection to daemon HTTP client</name>
  <files>internal/daemon/daemon.go, cmd/flowy-daemon/main.go</files>
  <behavior>
    - When cfg.Auth.DaemonToken is non-empty, all HTTP requests include "Authorization: Bearer {token}" header
    - When cfg.Auth.DaemonToken is empty, no Authorization header is added
    - Existing daemon behavior unchanged when no token configured
  </behavior>
  <action>
1. Add `bearerTransport` to `internal/daemon/daemon.go`:
   ```go
   type bearerTransport struct {
       token string
       base  http.RoundTripper
   }

   func (t *bearerTransport) RoundTrip(req *http.Request) (*http.Response, error) {
       if t.token != "" {
           req = req.Clone(req.Context())
           req.Header.Set("Authorization", "Bearer "+t.token)
       }
       return t.base.RoundTrip(req)
   }
   ```

2. Update `daemon.New()` to use the bearer transport:
   ```go
   func New(cfg *config.Config, daemonID string) *Daemon {
       transport := http.RoundTripper(http.DefaultTransport)
       if cfg.Auth.DaemonToken != "" {
           transport = &bearerTransport{
               token: cfg.Auth.DaemonToken,
               base:  http.DefaultTransport,
           }
       }
       return &Daemon{
           cfg:      cfg,
           daemonID: daemonID,
           client:   &http.Client{Timeout: 35 * time.Second, Transport: transport},
       }
   }
   ```

3. No changes needed to `cmd/flowy-daemon/main.go` — the config already loads `Auth.DaemonToken` from YAML via `config.Load`. Verify this by confirming `daemon.New(cfg, daemonID)` passes the full config.

4. Add a test in `internal/daemon/daemon.go` or a `_test.go` file:
   - TestBearerTransport_WithToken: create transport with token, make request via httptest server, verify Authorization header present.
   - TestBearerTransport_WithoutToken: create transport with empty token, make request, verify no Authorization header.
