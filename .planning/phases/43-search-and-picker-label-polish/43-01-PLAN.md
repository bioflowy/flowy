# Plan 43-01: Files Tab Search and Filtering

**Phase:** 43 - Search and Picker Label Polish
**Status:** Completed

## Objective

Allow users to filter managed files by label, path, and type without changing the underlying API contract.

## Implementation Outline

1. Add a free-text filter that matches label, path, and type.
2. Add a client-side type filter control.
3. Render an explicit no-match state when filters hide all rows.
