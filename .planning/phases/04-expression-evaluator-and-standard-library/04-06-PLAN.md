**stdContains:** args[0]=ArrayValue, args[1]=search value. Iterate items; use primitiveEqual(item, args[1]). Return BooleanValue{true} if any match, else BooleanValue{false}.

**stdContainsKey:** args[0]=MapValue, args[1]=key. Iterate Entries; use primitiveEqual(entry.Key, args[1]). Return BooleanValue.
