  <action>
Create wdl/eval/stdlib_array.go with all STDLIB-03 implementations.

**stdLength:** len(args[0].(values.ArrayValue).Items) -> IntValue.

**stdFlatten:** Recurse into ArrayValue.Items and concatenate. The result ItemType comes from the inner array's ItemType.

**stdTranspose:** Standard matrix transpose. Assumes all rows have same length; if any row length differs from first, continue (WDL spec says undefined behavior for jagged arrays — do best effort).

**stdZip:** Iterate both arrays element-wise. Same length required; if different lengths, use shorter. Each pair becomes PairValue.

**stdCross:** Nested loop: for each element in first array, for each element in second array, emit PairValue.

**stdPrefix, stdSuffix:** For each item in array, convert to string with fmt.Sprintf("%v") or type-assert to concrete type and use .Value; prefix/append the given prefix/suffix string.

**stdQuote, stdSquote:** Wrap each element's string form in "" or ''.

**stdUnzip:** Split []PairValue into two arrays. Return PairValue{Left: ArrayValue of lefts, Right: ArrayValue of rights}.

**stdSelectAll:** Filter out NullValue entries from array. Return ArrayValue of remaining items.

**stdSelectFirst:** Return first non-NullValue item; EvalError if none found.

**stdChunk:** Validate n > 0. Slice windows of size n. Last window may be smaller. Return ArrayValue of ArrayValues. The outer ArrayType.ItemType = the input array type.

Add init() to register all 14 STDLIB-03 functions.

In stdlib_test.go: remove t.Skip() from TestStdlibArray and implement test cases from the behavior list.

**wdl/eval/stdlib_string.go:**

**stdSub:** args[0]=StringValue input, args[1]=StringValue pattern, args[2]=StringValue replacement.
regexp.MustCompile(pattern).ReplaceAllString(input, replacement) -> StringValue.

**stdFind:** regexp.MustCompile(pattern).FindString(input). If found return StringValue{match}. If not found return NullValue{}.

**stdMatches:** regexp.MustCompile(pattern). Use regexp.MatchString but anchor with "^"+pattern+"$" to require whole-string match. Return BooleanValue.

**stdJoinPaths:** Runtime overload dispatch based on argument types:
1. (FileValue, StringValue) -> filepath.Join(arg0, arg1) -> FileValue
2. (FileValue, ArrayValue) -> filepath.Join(arg0, arg1Items...) -> FileValue
3. (ArrayValue) -> filepath.Join(items...) -> FileValue
Detect which overload by type-asserting args[0] and checking len(args).

Add init() to register sub, find, matches, join_paths.

**stdMin / stdMax:** Type dispatch: if both IntValue -> compare as int64, return IntValue. If both FloatValue -> compare as float64, return FloatValue. If mixed -> promote Int to float64, return FloatValue.
