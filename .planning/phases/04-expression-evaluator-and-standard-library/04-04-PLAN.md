Implement read functions using os.ReadFile and bufio/strings:

**stdReadLines:** Read file, TrimRight trailing "\n", split by "\n". Each line becomes StringValue. Return ArrayValue{Type: types.ArrayType{ItemType: types.StringType{}}}.

**stdReadTsv:** Read file, split into lines (TrimRight "\n"), for each non-empty line split by "\t" to get fields. Each field becomes StringValue. Each row is ArrayValue. Return ArrayValue of ArrayValues. Use only `Array[Array[String]] read_tsv(File)` overload (no header overload per research open question).

**stdReadMap:** Read file, split into lines, each line split by "\t" into key+value. Build MapEntry slice. Return MapValue{Type: types.MapType{KeyType: types.StringType{}, ValueType: types.StringType{}}}.

**stdReadJson:** Read file, json.Unmarshal into interface{}. Write a helper jsonToValue(v interface{}) values.Value that recursively converts:
- bool -> BooleanValue
- float64 (JSON numbers are float64) -> IntValue if whole number (math.Trunc(x)==x), else FloatValue
- string -> StringValue
- []interface{} -> ArrayValue
- map[string]interface{} -> MapValue with string keys -> StringValue
- nil -> NullValue{}

**stdReadBoolean, stdReadInt, stdReadFloat, stdReadString:** Read file, TrimSpace the content, parse with strconv (ParseBool, ParseInt base 10 64-bit, ParseFloat 64-bit). Return typed Value or EvalError.
