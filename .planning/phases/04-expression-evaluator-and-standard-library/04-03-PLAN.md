type StringPart interface { isStringPart() }

type RawStringPart struct {
    Val string  // literal text segment
}

type PlaceholderPart struct {
    Pos     ast.Pos

}

```go
type StringExpr struct {
    Pos
    Parts []StringPart  // RawStringPart and PlaceholderPart segments
}
type CommandExpr struct {
    Pos
    Parts []StringPart  // same segments
}
```

Placeholder option semantics (WDL 1.2):
  "sep"     — for Array values: join items with this separator string
  "default" — for NullValue: emit this string instead of empty
  "true"    — for BooleanValue true: emit this string instead of "true"
  "false"   — for BooleanValue false: emit this string instead of "false"
  (no option on NullValue) — emit empty string ""

  <files>wdl/eval/command.go, wdl/eval/command_test.go</files>
  <behavior>
    - computeMinIndent("    echo hello\n    echo world\n") -> 4
    - computeMinIndent("    echo hello\n\n    echo world\n") -> 4 (empty lines excluded)
    - computeMinIndent("    echo hello\n   \n    echo world\n") -> 4 (whitespace-only lines excluded)
    - computeMinIndent("echo hello\n") -> 0
    - computeMinIndent("") -> 0 (no lines -> 0)
    - applyDedentAndSubstitute with minIndent=4: strips 4 leading spaces from each non-empty line
    - Sentinel "~{}" is replaced with evaluated values in order of appearance
    - Command with placeholder BEFORE indent calculation: sentinel placed at placeholder position, indent computed on sentinel string (not expanded value)
    - Command "    echo ~{name}\n    echo done\n" with name="alice" -> "echo alice\necho done\n"
    - Command with all-whitespace-only line: that line is preserved as-is (no stripping, not included in min-indent)
  </behavior>
  <action>
Create wdl/eval/command.go with these functions:

**computeMinIndent(s string) int:**
- Split s by "\n"
- For each line, if strings.TrimSpace(line) == "" skip it (empty or whitespace-only)
- Count leading spaces (or tabs — treat tab as 1 char, matching miniwdl) of non-skipped lines
- Return minimum; if no non-empty lines return 0

**applyDedentAndSubstitute(sentinel string, minIndent int, parts []string, marker string) string:**
- Split sentinel by "\n"
- For each line: if non-empty, strip first minIndent characters (up to line length)
- Rejoin lines with "\n"
- Replace each occurrence of marker ("~{}") with the next element from parts slice in order

**Helper valueToString(v values.Value, opts map[string]string) string:**
- NullValue: return opts["default"] if key exists, else ""
- BooleanValue: if true return opts["true"] if exists else "true"; if false return opts["false"] if exists else "false"
- IntValue: return strconv.FormatInt(v.Value, 10)
- FloatValue: return strconv.FormatFloat(v.Value, 'g', -1, 64)
- StringValue: return v.Value
- FileValue: return v.Value (the path string)
- DirectoryValue: return v.Value
- ArrayValue with "sep" option: join items with opts["sep"] using recursive valueToString(item, nil) for each
- ArrayValue without "sep": join with space " "
- Other compound types: fmt.Sprintf("%v", v) as fallback

Implement TestCommandDedent and TestCommandDedentEdgeCases in command_test.go:
- Test computeMinIndent directly with cases from the behavior list above
- Test applyDedentAndSubstitute directly
- Test valueToString for NullValue with/without default, BooleanValue with true/false options, ArrayValue with sep option

All tests must be direct unit tests of these pure functions (no Eval() needed).
