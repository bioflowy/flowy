    2. In the `newRouter()` function, insert the CORS middleware block immediately after `r.Use(middleware.Recoverer)` and before the `r.NotFound(...)` call:
       ```go
       // CORS: config-gated, dev-only. Must be registered at top-level before
       // JWT middleware so OPTIONS preflight requests are handled without auth.
       if s.cfg.CORS.Enabled {
           r.Use(cors.Handler(cors.Options{
               AllowedOrigins:   s.cfg.CORS.AllowedOrigins,
               AllowedMethods:   []string{"GET", "POST", "PUT", "DELETE", "OPTIONS"},
               AllowedHeaders:   []string{"Accept", "Authorization", "Content-Type"},
               AllowCredentials: false,
               MaxAge:           300,
           }))
       }
       ```

       CRITICAL placement: The CORS middleware MUST be before JWT middleware (which is inside `r.Group`).
       If placed inside a route group, OPTIONS preflight (which has no Authorization header) will be
       rejected by JWT middleware before CORS headers are set. This is Pitfall 3 from RESEARCH.md.
