    **CreateUserDialog (web/src/features/users/CreateUserDialog.tsx):**
    Follow the ChangePasswordDialog pattern exactly. Controlled dialog with `open` and `onOpenChange` props.

    Zod schema:
    ```typescript
    const createUserSchema = z.object({
      username: z.string().min(1, 'Username is required'),
      password: z.string().min(8, 'Password must be at least 8 characters'),
      globalRole: z.enum(['admin', 'executor', 'viewer']),
      displayName: z.string().optional(),
      email: z.string().email('Invalid email').optional().or(z.literal('')),
    })
    ```
    Default values: `{ username: '', password: '', globalRole: 'viewer', displayName: '', email: '' }`

    On submit, call `useCreateUser().mutateAsync()` with body mapped to snake_case:
    ```typescript
    { username, password, global_role: values.globalRole, display_name: values.displayName, email: values.email }
    ```
    On success: `toast.success('User created.')`, `form.reset()`, `onOpenChange(false)`.
    On error: if ApiError message includes "exists" or "taken", set root error "Username already exists." Otherwise "Something went wrong. Please try again."

    UI layout per UI-SPEC:
    - DialogTitle: "Create User"
    - Fields: Username (Input type="text" autocomplete="off"), Password (Input type="password" autocomplete="new-password"), Role (Select with options admin/executor/viewer), Display Name (Input type="text"), Email (Input type="email")
    - Footer: Cancel (variant="ghost") + Create (variant="default", shows Loader2 + "Creating..." when submitting)

    **ResetPasswordDialog (web/src/features/users/ResetPasswordDialog.tsx):**
    Follow ChangePasswordDialog pattern. Props: `open`, `onOpenChange`, `user: { id: string; username: string } | null`.

    Zod schema:
    ```typescript
    const resetPasswordSchema = z.object({
      newPassword: z.string().min(8, 'Password must be at least 8 characters.'),
      confirmPassword: z.string().min(1, 'Please confirm the password'),
    }).refine((data) => data.newPassword === data.confirmPassword, {

      path: ['confirmPassword'],
    })
    ```

    On submit: `useResetPassword().mutateAsync({ userId: user.id, newPassword: values.newPassword })`.
