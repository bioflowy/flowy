    **memory.go**: Implement `parseMemoryString(s string) (int64, error)` with memUnits map covering B, bytes, kB, KB, MB, GB, TB, KiB, MiB, GiB, TiB. Handle bare integers. Use `strings.Fields` to split. Parse the numeric part as float64 to handle "1.5 GiB".

    **runtime.go**: Define `DockerConfig` struct:
    ```go
    type DockerConfig struct {
        Image    string
        Memory   int64   // bytes
        NanoCPUs int64   // nanocpus
    }
    ```
    Implement `parseRuntime(task *ast.Task, env *eval.Env) (DockerConfig, error)`:
    - Check `task.Requirements` first (WDL 1.2 preferred), fall back to `task.Runtime`
    - For "container" key (check "container" first, then "docker"): evaluate expression via `eval.Eval`, extract string, set as Image. Default: "ubuntu:latest".
    - For "cpu": evaluate, convert to int64, multiply by 1e9 for NanoCPUs
    - For "memory": evaluate, call parseMemoryString
    - Use `eval.ExecContext{}` (empty) when evaluating runtime expressions — they should not reference task outputs

    **inputs.go**: Implement `bindInputs(task *ast.Task, jsonInputs map[string]interface{}, pm *PathMap) (*eval.Env, []string, error)`:
    - Returns env (bindings), envVars (for env-modified inputs), error
    - Walk `task.Inputs`: for each Decl, check `jsonInputs[decl.Name]`
    - If present: call `jsonToWDLValue(raw, decl.Type)` to convert JSON value using type hints from decl.Type. This function extends the `jsonToValue` pattern from `eval/stdlib_fileio.go` but uses the declaration type to guide conversion (e.g., string -> FileValue when decl.Type is FileType, string -> DirectoryValue when decl.Type is DirectoryType)
    - If absent and `decl.Expr != nil`: evaluate default via `eval.Eval(decl.Expr, env, eval.ExecContext{})`
    - If absent and `decl.Expr == nil` and type is not optional: return error "missing required input"
    - If absent and type is optional: bind NullValue{}
    - After conversion: call `collectPaths(val, pm)` to walk the value and register all File/Directory paths in PathMap
    - If `decl.Env == true`: add `decl.Name + "=" + stringified_value` to envVars list (use simple fmt.Sprintf for stringification)
    - Define the value in env

    **Note on jsonToWDLValue**: This is a type-aware version of `jsonToValue`. Key differences from eval's version:
    - When decl.Type is `types.FileType{}` and JSON value is string: return `FileValue{Value: string}`
    - When decl.Type is `types.DirectoryType{}` and JSON value is string: return `DirectoryValue{Value: string}`
    - When decl.Type is `types.IntType{}` and JSON value is float64: always promote to IntValue (truncate)
    - For compound types (Array, Map, Pair): recurse with item/key/value types
    - Fall back to untyped `jsonToValue`-style conversion when type is AnyType

    Test files: Use table-driven tests constructing ast.Task with appropriate Decl nodes.
