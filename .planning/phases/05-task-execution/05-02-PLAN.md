    - buildCommand writes the expanded command to execDir/command file
    - buildCommand returns the host path to the written command script
    - collectOutputs evaluates output decls with ExecContext pointing to host work dir
    - collectOutputs returns map[string]values.Value keyed by output declaration name
    - collectOutputs with a File-type output expression returns FileValue with host path
  </behavior>
  <action>
    **command.go**: Implement `buildCommand(task *ast.Task, env *eval.Env, pm *PathMap, execDir string) (string, error)`:
    1. Create a translated env by walking env bindings and calling `pm.TranslateValue()` on each value. Since `eval.Env` is a linked-list with unexported fields, create a new Env and copy all bindings with translated values. Helper: `translateEnv(env *eval.Env, pm *PathMap) *eval.Env` — walks bindings map (needs access; if bindings is unexported, iterate by calling Lookup for known names from task.Inputs + task.Decls, or add a `ForEach` method or `Bindings()` accessor to eval.Env).

    **IMPORTANT**: If `eval.Env.bindings` is unexported and has no iterator method, add a `ForEach(fn func(string, values.Value))` method to `wdl/eval/env.go` that walks the current scope's bindings only (do NOT walk parent). This is a minimal change that preserves encapsulation.

    2. Evaluate the command expression: `eval.Eval(task.Command, translatedEnv, eval.ExecContext{})` — ExecContext is empty during command expansion (stdout/stderr not yet captured)
    3. Extract the string value from the result
    4. Write the command string to `filepath.Join(execDir, "command")` with mode 0644
    5. Return the path to the command file

    Also evaluate any private declarations (`task.Decls`) in the env before command expansion — iterate `task.Decls`, evaluate each `decl.Expr` via `eval.Eval`, and define in env. These may be needed by command expressions.

    **outputs.go**: Implement `collectOutputs(task *ast.Task, env *eval.Env, ctx eval.ExecContext, pm *PathMap) (map[string]values.Value, error)`:
    1. Create a child env from the input env (for output-scope bindings)
    2. For each decl in `task.Outputs`:
       - Evaluate `decl.Expr` via `eval.Eval(decl.Expr, outEnv, ctx)` with the populated ExecContext
       - The ExecContext.WorkDir points to the host work directory, so glob() and file operations work on host paths
       - Call `pm.UntranslateValue()` on the result to convert any remaining container paths back to host paths (safety net)
       - Store in result map keyed by `decl.Name`
       - Define in outEnv for subsequent output expressions that may reference earlier outputs
    3. Return the output map

    Note: Output expressions like `stdout()` and `stderr()` will use `ctx.StdoutPath` and `ctx.StderrPath` automatically — the stdlib functions already handle this.
  </action>

  <action>
    **task.go** — Replace the RunTask stub with the full orchestration pipeline:
    ```
    func RunTask(ctx, task, jsonInputs, runner, execRoot) (map[string]values.Value, error):
      1. Create execution directory: filepath.Join(execRoot, task.Name)
         - Create work/ subdirectory (bind-mounted as /mnt/outputs in container)
      2. pm := NewPathMap()
      3. env, envVars, err := bindInputs(task, jsonInputs, pm)
      4. config, err := parseRuntime(task, env)
      5. Evaluate private declarations (task.Decls) into env
      6. commandPath, err := buildCommand(task, env, pm, execDir)
      7. Add command file to pm.Binds: commandPath:/mnt/inputs/_command:ro
      8. Add work dir to pm.Binds: workDir:/mnt/outputs:rw
      9. Construct RunRequest{
           Image: config.Image,
           Command: []string{"bash", "/mnt/inputs/_command"},
           Binds: pm.Binds() + command bind + work bind,
           Env: envVars,
           Memory: config.Memory,
           NanoCPUs: config.NanoCPUs,
           WorkDir: "/mnt/outputs",
         }
      10. result, err := runner.Run(ctx, req)
      11. Write stdout.txt, stderr.txt, rc files to execDir
      12. If result.ExitCode != 0: return nil, &TaskError{task.Name, result.ExitCode, string(result.Stderr)}
      13. ctx := eval.ExecContext{
            WorkDir: workDir,
            StdoutPath: filepath.Join(execDir, "stdout.txt"),
            StderrPath: filepath.Join(execDir, "stderr.txt"),
          }
      14. outputs, err := collectOutputs(task, env, ctx, pm)
      15. Return outputs, nil
    ```

    **task_test.go** — Implement ShellRunner mock and end-to-end tests:

    ShellRunner struct (implements ContainerRunner):
    - Finds the _command bind in req.Binds
    - Reads the command script file
    - Executes via `exec.CommandContext(ctx, "bash", scriptPath)`
    - Sets cmd.Dir to the host path corresponding to /mnt/outputs (found from req.Binds)
    - Sets cmd.Env from req.Env
    - Captures stdout/stderr
    - Returns RunResult with exit code

    Tests:
    1. **TestRunTaskEcho**: Task with `command { echo "hello" }`, no inputs, one String output reading stdout(). Verify output["msg"] == "hello\n".
    2. **TestRunTaskWithInputs**: Task with Int and String inputs from JSON, command using placeholders. Verify command file contains expanded values.
    3. **TestRunTaskFailure**: Task with `command { exit 1 }`. Verify *TaskError returned with ExitCode=1.
    4. **TestRunTaskMissingInput**: Task with required input, empty JSON map. Verify error returned before execution.
    5. **TestRunTaskFileOutput**: Task with `command { echo "data" > result.txt }`, File output using `"${workDir}/result.txt"` or glob. Verify FileValue points to host path.

    Note: ShellRunner ignores bind-mount semantics (files are already host-local). It executes the command script directly on the host. The test constructs ast.Task nodes programmatically (no WDL parsing needed — matches established pattern from eval tests).
