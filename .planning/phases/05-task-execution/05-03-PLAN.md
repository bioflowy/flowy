    2. **docker.go**: Implement DockerRunner struct and NewDockerRunner() constructor.

    `DockerRunner` struct holds no fields (stateless — creates client per Run call for simplicity and thread-safety).

    `NewDockerRunner() *DockerRunner` — returns `&DockerRunner{}`.

    `Run(ctx context.Context, req RunRequest) (RunResult, error)`:
    Follow the exact lifecycle from RESEARCH.md Pattern 3:

    a) Create Docker client:
    ```go
    cli, err := client.NewClientWithOpts(client.FromEnv, client.WithAPIVersionNegotiation())
    defer cli.Close()
    ```

    b) Pull image (implicit — pull even if cached; Docker handles no-op if up-to-date):
    ```go
    pullResp, err := cli.ImagePull(ctx, req.Image, image.PullOptions{})
    // CRITICAL: drain response body to avoid connection pool exhaustion
    io.Copy(io.Discard, pullResp)
    pullResp.Close()
    ```

    c) Create container:
    ```go
    resp, err := cli.ContainerCreate(ctx,
        &container.Config{
            Image:      req.Image,
            Cmd:        req.Command,
            Env:        req.Env,
            WorkingDir: req.WorkDir,
        },
        &container.HostConfig{
            Binds: req.Binds,
            Resources: container.Resources{
                Memory:   req.Memory,
                NanoCPUs: req.NanoCPUs,
            },
        },
        nil, nil, "", // no network, no platform, no name
    )
    ```

    d) CRITICAL — Set up wait BEFORE start:
    ```go
    waitCh, errCh := cli.ContainerWait(ctx, resp.ID, container.WaitConditionNextExit)
    ```

    e) Start container:
    ```go
    cli.ContainerStart(ctx, resp.ID, container.StartOptions{})
    // On error: force remove container and return
    ```

    f) Wait for completion with context cancellation support:
    ```go
    select {
    case waitResp := <-waitCh:
        exitCode = int(waitResp.StatusCode)
    case err := <-errCh:
        // force remove and return error
    case <-ctx.Done():
        // force remove and return ctx.Err()
    }
    ```

    g) Collect logs with stdcopy demuxing:
    ```go
    logResp, err := cli.ContainerLogs(ctx, resp.ID, container.LogsOptions{
        ShowStdout: true, ShowStderr: true,
    })
    var stdoutBuf, stderrBuf bytes.Buffer
    stdcopy.StdCopy(&stdoutBuf, &stderrBuf, logResp)
    logResp.Close()
    ```

    h) Remove container (non-force — container already exited):
    ```go
    cli.ContainerRemove(ctx, resp.ID, container.RemoveOptions{})
    ```

    i) Return RunResult{ExitCode, Stdout, Stderr}

    **Error handling pattern**: Use a `cleanup` function that force-removes the container. Call it in every error path after ContainerCreate succeeds. Use `defer` with a containerID variable that is set after create.

    **Do NOT use AutoRemove: true** — it prevents log collection.

    3. **docker_test.go**: Write integration test gated with `//go:build integration` build tag.

    ```go
    //go:build integration

    package task

    import (
        "context"
        "testing"
    )

    func TestDockerRunner(t *testing.T) {
        runner := NewDockerRunner()
        result, err := runner.Run(context.Background(), RunRequest{
            Image:   "alpine:latest",
            Command: []string{"echo", "hello"},
        })
        if err != nil {
            t.Fatalf("Run failed: %v", err)
        }
        if result.ExitCode != 0 {
            t.Fatalf("expected exit code 0, got %d", result.ExitCode)
        }
        if got := string(result.Stdout); got != "hello\n" {
            t.Errorf("stdout = %q, want %q", got, "hello\n")
        }
    }
    ```

    Add a second subtest for non-zero exit code:
    - Run `sh -c "echo err >&2; exit 42"` and verify ExitCode=42 and stderr contains "err".
