   ```typescript
     return useQuery<RegistryInputsResponse>({
       queryKey: ['projects', slug, 'registry', name, 'inputs', tag],
       queryFn: () => apiClient.get(`/projects/${slug}/registry/${name}/inputs?tag=${encodeURIComponent(tag)}`),
       enabled: !!slug && !!name && !!tag,
     })
   }
   ```

   Add `useRunWorkflow` mutation hook:
   ```typescript
   export function useRunWorkflow(slug: string) {
     const queryClient = useQueryClient()
     return useMutation<{ run_id: string }, Error, { registry_ref: string; inputs: Record<string, unknown> }>({
       mutationFn: ({ registry_ref, inputs }) =>
         apiClient.post(`/projects/${slug}/workflows`, { registry_ref, inputs }),
       onSuccess: () =>
         queryClient.invalidateQueries({ queryKey: ['projects', slug, 'runs'] }),
     })
   }
   ```

   Ensure `useQueryClient` and `useMutation` are imported from `@tanstack/react-query` (add to existing import).

**Component structure:**

1. **Version/tag selector:** Compute `defaultTag` from versions — prefer "latest" if any version has it, else first version's first tag. Use `useState` for `selectedTag`, initialized to `defaultTag`. Reset `selectedTag` when `defaultTag` changes (useEffect). Use `useRegistryInputs(slug, name, selectedTag)` to fetch inputs for the selected tag.

2. **Dynamic zod schema:** Use `useMemo` keyed on `inputsData?.inputs` to build a `z.object(shape)`:
   - String: `z.string().min(1, '{name} is required')`
   - Int: `z.coerce.number().int('{name} must be an integer')`
   - Float: `z.coerce.number({ message: '{name} must be a number' })`
   - Boolean: `z.boolean()`
   - File: `z.string().min(1, '{name} is required')`
   - Array/Map/Struct (match with `type.startsWith()`): `z.string().min(1).refine(v => { try { JSON.parse(v); return true } catch { return false } }, '{name} must be valid JSON')`
   - If `input.optional` is true, wrap with `.optional().or(z.literal(''))`
   Use `input.optional` field (not `?` suffix in type string) for optional detection.

3. **Default values:** Use `useMemo` to build default values from `inputsData?.inputs`:
   - Boolean fields: `input.default === 'true'` or `false`
   - Other fields: `input.default ?? ''`

4. **Form setup:** `useForm` with `zodResolver(schema)`, `defaultValues`. Add `useEffect` to call `form.reset(computedDefaults)` whenever `inputsData?.inputs` changes (to handle version/tag change).

5. **Form fields rendering:** For each input in `inputsData?.inputs`, render a `FormField`:
   - **String**: `<Input type="text" placeholder="Enter a string value" />`
   - **Int**: `<Input type="number" step="1" placeholder="Enter an integer" />`
   - **Float**: `<Input type="number" step="any" placeholder="Enter a decimal number" />`
   - **Boolean**: `<Checkbox checked={field.value} onCheckedChange={field.onChange} />` in a flex row with label inline (per UI spec: `className="flex flex-row items-start space-x-3 space-y-0"`)
   - **File**: `<Input type="text" placeholder="e.g., s3://bucket/path or /absolute/path" />` with an `Info` icon wrapped in `TooltipProvider > Tooltip > TooltipTrigger > TooltipContent`. Tooltip content: "Enter a server-accessible path. Browser file paths are not supported. Use s3://, /absolute/path, or another path the server can resolve."
   - **Array/Map/Struct** (default): `<Textarea placeholder="Enter valid JSON" />` with helper text below: `<p className="text-xs text-muted-foreground">Use JSON format, e.g. ["a", "b"]</p>`
   - Optional fields: append " (optional)" in `text-muted-foreground` to the label
   - Default value annotation: if `input.default` is not null, show `<p className="text-xs text-muted-foreground">(default: {input.default})</p>` beneath the input

6. **Loading/error/empty states (inside dialog form area):**
   - `inputsLoading`: Three skeleton rows: `<div className="space-y-4">{Array.from({length:3}).map((_,i) => <div key={i}><div className="h-3 w-24 animate-pulse rounded bg-muted" /><div className="h-4 w-full animate-pulse rounded bg-muted mt-2" /></div>)}</div>`
   - `inputsError`: `<p className="text-muted-foreground text-sm">Failed to load workflow inputs. Please close and try again.</p>` and disable submit button
   - Empty inputs (data loaded, `inputs.length === 0`): `<p className="text-muted-foreground text-sm">This workflow declares no inputs. Click Run Workflow to execute with defaults.</p>`

7. **Submit handler (`onSubmit`):**
   - Build inputs JSON: iterate `inputsData.inputs`, include only fields where value is non-empty (skip empty optional). For Array/Map/Struct types, `JSON.parse(value)` before including. For Boolean optional fields, include only if explicitly toggled.
   - Call `runWorkflow.mutateAsync({ registry_ref: \`${name}:${selectedTag}\`, inputs })`.
   - On success: `toast.success('Run submitted.')`, `form.reset()`, `onOpenChange(false)`, then `navigate(\`/projects/${slug}/runs/${result.run_id}\`)`.
   - On error: `if (err instanceof ApiError)`: status 400 -> `toast.error('Invalid inputs. Check the values and try again.')`, 404 -> `toast.error('Workflow version not found.')`, else -> `toast.error('Server error. Please try again.')`. If not ApiError: `toast.error('Server error. Please try again.')`.

8. **Dialog structure:**
   - `<Dialog open={open} onOpenChange={handleOpenChange}>`
   - `<DialogContent className="sm:max-w-lg">`
   - `<DialogHeader>` with title "Run Workflow" and description "Configure inputs and submit execution."
   - Version `<Select>` with label "Version", placeholder "Select a version". Options: iterate versions, for each version show each tag as a SelectItem with value=tag. Display selected version's truncated digest below the Select as `<p className="text-xs text-muted-foreground">{truncatedDigest}</p>`.
   - `<Separator />` between version selector and form inputs section.
   - Dynamic form fields section.
   - `<DialogFooter>` with "Discard" button (type="button", variant="ghost") and "Run Workflow" submit button (disabled when `isPending || inputsLoading || inputsError`). When pending: `<Loader2 className="mr-2 h-4 w-4 animate-spin" />Submitting...`.

9. **handleOpenChange:** On close (`!nextOpen`): `form.reset()`, reset `selectedTag` to `defaultTag`, then call `onOpenChange(nextOpen)`.
