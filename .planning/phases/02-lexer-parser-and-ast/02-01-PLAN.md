  <behavior>
    - Document struct has Version string, Tasks []*Task, Workflows []*Workflow, Structs []*StructDef, each with embedded Pos
    - Task struct has Name, Inputs []*Decl, Decls []*Decl, Command *CommandExpr, Outputs []*Decl, Runtime map[string]Expr, Requirements map[string]Expr, Hints map[string]any, Meta map[string]any, ParamMeta map[string]any
    - Workflow.Body is []WorkflowNode where WorkflowNode is an interface with isWorkflowNode() marker method; Call, Scatter, Conditional, Decl all implement it
    - Decl.Type is types.Type (imported from wdl/types); Decl.Expr is Expr (nil if unbound)
    - Every struct has embedded Pos as a plain field (not pointer), where Pos has File string, Line int, Col int
    - StructDef.Members is []*Decl with Expr==nil (unbound declarations only)
    - Call.After is []string for "after NAME" dependencies; Call.Inputs is map[string]Expr
    - StringExpr has Parts []StringPart where StringPart is an interface; RawStringPart{Val string} and PlaceholderPart{Pos Pos, Options map[string]string, Expr Expr} both implement StringPart
    - CommandExpr has Parts []StringPart and Style CommandStyle (CommandBrace or CommandHeredoc int const)
    - BinaryExpr.Op and UnaryExpr.Op are TokenType (int); this type is defined in wdl/lexer, so use int alias in ast package to avoid circular imports — define type TokenType = int in ast package with comment "matches lexer.TokenType"
    - Expr interface has a single marker method exprNode(); all expression node types implement it
  </behavior>
  <action>
Create wdl/ast/ast.go and wdl/ast/expr.go in a new wdl/ast/ directory.

ast.go: Define package ast. Import "github.com/bioflowy/flowy/wdl/types". Define:
- type Pos struct { File string; Line int; Col int }
- type WorkflowNode interface { isWorkflowNode() }
- type StringPart interface { isStringPart() }
- type RawStringPart struct { Val string } — implement isStringPart()
- type PlaceholderPart struct { Pos Pos; Options map[string]string; Expr Expr } — implement isStringPart()
- type CommandStyle int with consts CommandBrace CommandStyle = iota; CommandHeredoc
- type Document struct { Pos; Version string; Tasks []*Task; Workflows []*Workflow; Structs []*StructDef }
- type Task struct { Pos; Name string; Inputs []*Decl; Decls []*Decl; Command *CommandExpr; Outputs []*Decl; Runtime map[string]Expr; Requirements map[string]Expr; Hints map[string]any; Meta map[string]any; ParamMeta map[string]any }
- type Workflow struct { Pos; Name string; Inputs []*Decl; Body []WorkflowNode; Outputs []*Decl; Meta map[string]any; ParamMeta map[string]any }
- type Decl struct { Pos; Type types.Type; Name string; Expr Expr; Env bool } — Env is true for WDL 1.2 "env" modifier on task inputs; implement isWorkflowNode()
- type StructDef struct { Pos; Name string; Members []*Decl }
- type Call struct { Pos; Callee []string; Alias string; After []string; Inputs map[string]Expr } — implement isWorkflowNode()
- type Scatter struct { Pos; Variable string; Expr Expr; Body []WorkflowNode } — implement isWorkflowNode()
- type Conditional struct { Pos; Expr Expr; Body []WorkflowNode } — implement isWorkflowNode()

expr.go: Define package ast. Define:
- type TokenType = int (alias, avoids circular import with lexer)
- type Expr interface { exprNode() }
- type BoolLit struct { Pos; Value bool } — implement Expr
- type IntLit struct { Pos; Value int64 } — implement Expr
- type FloatLit struct { Pos; Value float64 } — implement Expr
- type NullLit struct { Pos } — implement Expr
- type StringExpr struct { Pos; Parts []StringPart } — implement Expr
- type CommandExpr struct { Pos; Parts []StringPart; Style CommandStyle } — implement Expr
- type ArrayExpr struct { Pos; Items []Expr } — implement Expr
- type MapItem struct { Key, Value Expr }
- type MapExpr struct { Pos; Items []MapItem } — implement Expr
- type PairExpr struct { Pos; Left, Right Expr } — implement Expr
- type StructMember struct { Name string; Value Expr }
- type StructExpr struct { Pos; TypeName string; Members []StructMember } — implement Expr
- type IfThenElse struct { Pos; Cond, Then, Else Expr } — implement Expr
- type BinaryExpr struct { Pos; Op TokenType; Left, Right Expr } — implement Expr
- type UnaryExpr struct { Pos; Op TokenType; Operand Expr } — implement Expr
- type IndexExpr struct { Pos; Collection, Index Expr } — implement Expr
- type GetExpr struct { Pos; Object Expr; Member string } — implement Expr
- type ApplyExpr struct { Pos; Name string; Args []Expr } — implement Expr
- type IdentExpr struct { Pos; Name string } — implement Expr

All exprNode() methods are empty marker methods: func (*T) exprNode() {}
All isWorkflowNode() methods are empty marker methods.
