  <behavior>
    - parseExpr(minBP int) (ast.Expr, error): Pratt core as in RESEARCH.md pattern. Call parsePrefixExpr() for lhs, then loop: peekInfix() returns (op TokenType, leftBP int, rightBP int, ok bool). If !ok or leftBP <= minBP, break. advance(), recurse parseExpr(rightBP) for rhs. Build ast.BinaryExpr.
    - parsePrefixExpr(): handles prefix tokens: tokTrue/tokFalse → ast.BoolLit, tokNull → ast.NullLit, tokIntLit → parse int64 → ast.IntLit, tokFloatLit → parse float64 → ast.FloatLit, tokStringOpen → parseStringExpr(), tokLParen → parseExpr(0) then expect(tokRParen), tokLBracket → parseArrayExpr(), tokLBrace → parseMapExpr(), tokNot/tokMinus → parseUnaryExpr(rightBP=70), tokIdent → parseIdentOrCallOrStruct(), tokIf → parseIfThenElse()
    - peekInfix(): maps current token type to (leftBP, rightBP) per the binding power table. Returns ok=false for non-infix tokens. After primary lhs is parsed, also handles tokLBracket (index access, no BP loop — just consume directly as postfix), tokDot (member access, postfix)
    - parseIdentOrCallOrStruct(): peek after identifier. If tokLParen → ast.ApplyExpr (function call, parse comma-separated args). If tokLBrace → ast.StructExpr (struct literal, parse "field: expr" pairs). Else → ast.IdentExpr. Qualified names (a.b.c after a) handled by GetExpr chaining: if tokDot after ident, consume and recurse.
    - parseStringExpr(): after tokStringOpen, collect Parts. Loop: on tokCommandContent → ast.RawStringPart{Val: tok.Val}; on tokPlaceholderOpen → parsePlaceholderPart(); on tokStringClose → break. Return ast.StringExpr{Parts: parts}. Placeholder options (sep=, true=, false=, default=) appear as extra tokens before the placeholder expression — parse them into Options map[string]string.
    - parsePlaceholderPart(): consume optional placeholder options (sequence of IDENT "=" STRING_OR_BOOL), then parse the placeholder expression via parseExpr(0), then expect(tokPlaceholderClose). Return ast.PlaceholderPart.
    - parseArrayExpr(): "[" expr ("," expr)* "]" → ast.ArrayExpr
    - parseMapExpr(): "{" (expr ":" expr) ("," (expr ":" expr))* "}" → ast.MapExpr; distinguish from StructExpr at call site (StructExpr starts with CNAME then {, MapExpr starts with { directly)
    - parseIfThenElse(): "if" expr "then" expr "else" expr → ast.IfThenElse; no braces, just keyword-delimited
    - ** right-associativity: in the BP table, tokStarStar has leftBP=60, rightBP=60. The Pratt loop condition is leftBP <= minBP (strict less-or-equal), so rightBP=60 causes the recursive call to use minBP=60, which means another ** at the same level will also be consumed by the right side → right-associative.
    - Replace the stub parseExpr in parser.go with a call to this real implementation. The stub method signature must match (same receiver type, same parameters).
