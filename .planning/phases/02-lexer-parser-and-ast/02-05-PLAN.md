  <behavior>
    - Parse(filename string, src []byte) (*ast.Document, error) is the public entry point. It creates a visited map and calls parseFile after writing src to a temp location OR passes src directly to avoid re-reading. Simplest approach: parseFile takes (path string, src []byte, visited map[string]bool). For root file, src is provided. For imported files, src is nil and parseFile calls os.ReadFile(abs) to load the file.
    - parseFile signature: func parseFile(path string, src []byte, visited map[string]bool) (*ast.Document, error)
    - Public Parse calls: abs, err := filepath.Abs(filename); if err != nil { return nil, ... }; then parseFile(abs, src, map[string]bool{})
    - Circular import detection: before parsing, check visited[abs]. If true, build the cycle message by iterating the visited map keys is insufficient — instead pass an []string chain parameter alongside visited to reconstruct the cycle path for the error message. Cycle message format: "circular import: a.wdl → b.wdl → a.wdl"
    - Import statement parsing (replaces the stub "imports not yet supported" error): "import" STRING_LITERAL ["as" CNAME] (import_alias)*. The string literal is the relative path to the imported file. "as" creates a namespace prefix (stored but not acted on in Phase 2). import_alias is "alias CNAME as CNAME" (renaming structs during import).
    - After parsing the imported document (via recursive parseFile), merge by name:
      - For each imported task: if any existing doc.Task has the same Name, return ParseError "duplicate task name: X (imported from Y)". Otherwise append.
      - Same for workflows and structs.
    - Import-aliased structs: if "alias OldName as NewName" present, rename the struct in the imported document before merging (update StructDef.Name and any Member types that reference OldName → NewName within the imported doc).
    - After all imports are resolved, remove import tracking state; the final ast.Document contains only tasks, workflows, and structs — no import nodes.
    - parseImport() parses the import statement tokens and returns importPath string, namespace string, aliases []importAlias; the caller handles the recursive load.
