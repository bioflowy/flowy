    - ParseError.Error() produces rustc-style output: "error: {message}\n  --> {file}:{line}:{col}\n   |\n{line} | {sourceLine}\n   |  {caret}" where caret is Col-1 spaces followed by ^
    - Parser struct wraps lexer.Lexer, stores current and peek tokens, file path, original source lines (for SourceLine in errors)
    - Parser has internal peek() lexer.Token, advance() lexer.Token, expect(tokType) (lexer.Token, error), errorf(pos ast.Pos, msg string, args ...any) *ParseError
    - parseVersion() parses "version 1.2" and returns the version string
    - parseStruct() parses "struct Name { unbound_decl* }" into *ast.StructDef; struct body allows only unbound declarations (no Expr)
    - parseDecl(bound bool) parses "Type Name [= Expr]" into *ast.Decl; when bound=false, Expr must be nil; type is parsed via parseType
    - parseTask() parses "task Name { task_section* command task_section* }" skeleton — fills Inputs, Outputs, Decls slices; for the command block, emits a stub *ast.CommandExpr with Parts collected from raw lexer tokens (tokCommandContent, placeholder sequences); Command body parsing is real in this plan
    - parseWorkflow() parses "workflow Name { workflow_element* }" skeleton — fills Inputs, Outputs, Body; scatter/conditional/call/decl all handled; call parsing handles "call name [as alias] [after name, name] { input: ... }"
    - parseTaskSection() dispatches on keyword: input{}, output{}, runtime{}, requirements{}, hints{}, meta{}, param_meta{}
    - parseMeta() and parseHints() store values as map[string]any (strings, numbers, booleans, arrays, nested maps) — these are not WDL expressions, they are JSON-like literals
    - parseType() lives in parse_types.go; parses WDL type syntax into types.Type: primitive keywords → typed struct, "Array" "[" type "]" ["+"] ["?"] → ArrayType{NonEmpty: sawPlus}, "Map" "[" type "," type "]" ["?"] → MapType, "Pair" "[" type "," type "]" ["?"] → PairType, identifier (CNAME) → StructType{Name: ident}; after any type, "?" makes Optional=true; "+?" sequence: peek at next TWO tokens — if tokPlus followed by tokQuestion, consume both and set NonEmpty=true, Optional=true
    - Expression parsing: for this plan, wherever an expression is needed (Decl.Expr, scatter expr, conditional expr, call inputs), call a stub parseExpr() that returns ast.IdentExpr{Name: "__expr_stub__"} and consumes tokens until the expected delimiter — this stub is replaced entirely by Plan 04

Create wdl/parser/parser.go:
- Import: "fmt", "strings", "strconv", "github.com/bioflowy/flowy/wdl/ast", "github.com/bioflowy/flowy/wdl/lexer", "github.com/bioflowy/flowy/wdl/types"
- ParseError struct and Error() method with rustc-style formatting (see RESEARCH.md code example)
- Parser struct: lexer *lexer.Lexer, cur lexer.Token, peeked lexer.Token, hasPeeked bool, sourceLines []string, file string
- Constructor: newParser(file string, src []byte) *Parser splits src by \n into sourceLines
- peek() returns peeked token without advancing
- advance() consumes and returns next token
- expect(tt lexer.TokenType) (lexer.Token, error): calls advance(), returns error if wrong type
- errorf(...) creates *ParseError using tok.Pos, sets SourceLine from sourceLines[pos.Line-1]
- parseDocument() *ast.Document: main entry; calls parseVersion if "version" keyword seen, then loops parsing document elements (task/workflow/struct/import); import handling is a stub that returns ParseError "imports not yet supported" (Plan 05 implements import resolution)
- parseStruct(), parseTask(), parseWorkflow(), parseDecl(), parseTaskSection(), parseMeta(), parseHints()
- parseCommandBlock(): after "command" keyword, detect { vs <<<. In brace mode, collect tokens until matching } counting brace depth at the OUTER command level. In heredoc mode, collect until >>>. Build []ast.StringPart by interleaving raw parts (tokCommandContent → ast.RawStringPart) with placeholder sequences (tokPlaceholderOpen...tokPlaceholderClose → ast.PlaceholderPart with stub Expr). Return *ast.CommandExpr.
- parseWorkflowElement(): dispatches on current token: tokInput/tokOutput → parseDecl sections; tokScatter → parseScatter; tokIf → parseConditional; tokCall → parseCall; else → parseDecl(true) for intermediate declaration
- parseCall(): "call" CNAME ["." CNAME]* ["as" CNAME] ["after" CNAME ("," CNAME)*] ["{" "input" ":" call_inputs "}"]
- Stub parseExpr(): scans forward to find the expected end token (passed as parameter) without consuming it; returns ast.IdentExpr{Pos: pos, Name: "__expr_stub__"}. This is TEMPORARY — Plan 04 replaces it with the real Pratt parser.
