## Interaction States

| State | Behavior |
|-------|---------|
| Dialog closed | PushWDLDialog not mounted / open=false |
| Dialog open, idle | Both fields empty, submit disabled until name is non-empty and file is selected |
| File selected, wrong extension | Inline FormMessage: "Only .wdl files are accepted. Please select a valid WDL file." — evaluated via zod refine before any network request |
| Submitting | Submit button shows Loader2 spinner + "Pushing...", both inputs disabled, cancel button disabled |
| Success | Dialog closes, success toast shown, `useRegistryEntries` query invalidated (list auto-refreshes) |
| Server 422 | Dialog stays open, toast.error with server message |
| Server 409 | Dialog stays open, toast.error with name-conflict copy |
| Other error | Dialog stays open, toast.error with generic copy |
| Dialog closed mid-form | `form.reset()` called on `onOpenChange(false)` — fields cleared |
