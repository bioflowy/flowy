**Threats:**
1. XSS via file content — mitigated: content sent as JSON string to server, not rendered as HTML; server parses WDL, not browser
2. CSRF — mitigated: Bearer token in Authorization header (not cookie-based)

```typescript
export function usePushWDL(slug: string) {
  const queryClient = useQueryClient()
  return useMutation<RegistryPushResponse, Error, { name: string; content: string }>({
    mutationFn: ({ name, content }) =>
      apiClient.post(`/projects/${slug}/registry`, { name, content }),
    onSuccess: () =>
      queryClient.invalidateQueries({ queryKey: ['projects', slug, 'registry'] }),
  })
}
```

```typescript
const pushWDLSchema = z.object({
  name: z
    .string()
    .min(1, 'Entry name is required')
    .max(64)
    .regex(/^[a-z0-9-]+$/, 'Only lowercase letters, numbers, and hyphens allowed'),
  file: z.any()
    .refine((fl: unknown) => fl instanceof FileList && fl.length > 0, 'Select a file')
    .refine(
      (fl: unknown) => fl instanceof FileList && fl.length > 0 && fl[0].name.endsWith('.wdl'),
      'Only .wdl files are accepted. Please select a valid WDL file.'
    ),
})
```

**Component structure:**
- `useForm<PushWDLFormValues>({ resolver: zodResolver(pushWDLSchema), defaultValues: { name: '', file: undefined }, mode: 'onChange' })` — mode onChange enables live validation for submit button state
- `const pushWDL = usePushWDL(slug)`
- `const isPending = form.formState.isSubmitting || pushWDL.isPending`
- `const fileInputRef = useRef<HTMLInputElement>(null)` — for resetting file input DOM value
- `handleOpenChange`: if closing, call `form.reset()` and `fileInputRef.current.value = ''`, then `onOpenChange(nextOpen)`

**onSubmit handler:**
1. Read file content via FileReader wrapped in a Promise (as shown in RESEARCH.md code examples)
2. Call `pushWDL.mutateAsync({ name: data.name, content })`
3. On success: show toast `"${result.name} pushed. Digest: ${shortDigest}"` where shortDigest is `result.digest.startsWith('sha256:') ? result.digest.slice(7, 23) + '...' : result.digest`
4. Then `form.reset()` and `onOpenChange(false)`
5. On error: check if `err instanceof ApiError` (import from `@/lib/apiClient`):
   - status 422: `toast.error(\`Invalid WDL: ${err.message}\`)`
   - status 409: `toast.error('Name already exists with a different kind. Choose a different entry name.')`
   - else: `toast.error('Something went wrong. Please try again.')`
