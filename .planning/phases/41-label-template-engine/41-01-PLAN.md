# Plan 41-01: Pure-Go Label Evaluation

**Phase:** 41 - Label Template Engine
**Status:** Completed

## Objective

Add a narrow template evaluator for managed-file labels without introducing shell execution semantics.

## Implementation Outline

1. Parse `parameter_meta.label` from workflow outputs.
2. Evaluate allowed expansion forms against workflow input string values.
3. Fall back to basename labels on any invalid or unsupported input.
