| ID | Threat | Severity | Mitigation |
|----|--------|----------|------------|
| T-37-01 | SQL injection via ManagedFile field values (path, file_type, label) | medium | All queries use parameterized placeholders (`?`) -- no string interpolation. Verified by code review of every ExecContext/QueryRowContext call in managed_files.go. |

</threat_model>

**Step 2 -- Add ManagedFile struct to store.go** (per D-05):

Add after the `ProvenanceDetail` struct in `internal/store/store.go`:
```go
// ManagedFile represents a file tracked in the project library.
// RunID is nil for manually imported files that have no originating run.
type ManagedFile struct {
    ID        string
    ProjectID string
    RunID     *string // nil for manually imported files
    Path      string
    FileType  string
    Label     string
    Size      int64
    CreatedAt time.Time
}
```

**Step 3 -- Add interface methods to Store** (per D-06, D-07, D-08):

Add a new `// ManagedFile operations` section to the `Store` interface in `store.go`, before the `// Lifecycle` section:
```go
// ManagedFile operations

// CreateManagedFile persists a new managed file. f.ID must be set by the caller.
CreateManagedFile(ctx context.Context, f *ManagedFile) error
// ListManagedFiles returns all managed files for the given project.
ListManagedFiles(ctx context.Context, projectID string) ([]ManagedFile, error)
// GetManagedFileByID returns the managed file with the given ID.
GetManagedFileByID(ctx context.Context, id string) (*ManagedFile, error)
// DeleteManagedFile removes the managed file record with the given ID.
DeleteManagedFile(ctx context.Context, id string) error
// CompleteRun atomically marks a run as COMPLETED with the given outputs and
// inserts any provided managed file records in a single transaction.
// Pass nil or empty slice for files when no file registration is needed.
CompleteRun(ctx context.Context, runID string, projectID string, outputsJSON string, files []ManagedFile) error
```

**Step 4 -- Create managed_files.go** with SQLiteStore implementations:

Create `internal/store/sqlite/managed_files.go` with package `sqlite`, importing `context`, `database/sql`, `fmt`, and `github.com/bioflowy/flowy/internal/store`.

Implement:

1. `CreateManagedFile` -- INSERT into managed_files using `s.writer.ExecContext` with parameterized `?`. Columns: id, project_id, run_id, path, file_type, label, size. Omit created_at (uses DB DEFAULT).

2. `ListManagedFiles` -- SELECT all columns FROM managed_files WHERE project_id = ? ORDER BY created_at DESC using `s.reader.QueryContext`. Scan each row using a `scanManagedFileRows` helper that uses `sql.NullString` for run_id (convert to `*string` when Valid). Return `[]store.ManagedFile{}` (empty non-nil slice) when no rows.

3. `GetManagedFileByID` -- SELECT all columns FROM managed_files WHERE id = ? using `s.reader.QueryRowContext`. Use a `scanManagedFile` helper with `sql.NullString` for run_id. Return wrapped error on `sql.ErrNoRows`.

4. `DeleteManagedFile` -- DELETE FROM managed_files WHERE id = ? using `s.writer.ExecContext`.

5. `CompleteRun` (per D-08, D-09, D-10, D-11) -- Use `s.writer.BeginTx(ctx, nil)` to start a transaction. `defer tx.Rollback()`. Execute UPDATE runs SET state = 'COMPLETED', outputs_json = ?, updated_at = datetime('now') WHERE id = ? using `tx.ExecContext`. Then loop over files slice and INSERT each into managed_files via `tx.ExecContext`. Finally `tx.Commit()`. All errors wrapped with `fmt.Errorf("sqlite: CompleteRun ...: %w", err)`.
