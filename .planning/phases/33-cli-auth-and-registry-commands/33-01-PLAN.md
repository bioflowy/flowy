<threat_model>
## Threat Model

### T1: Credential file readable by other users (HIGH)
- **Attack:** Other users on shared system read JWT from ~/.flowy/credentials.yaml
- **Mitigation:** Write file with mode 0600, directory with mode 0700. Verify in tests.
- **Residual risk:** LOW after mitigation

### T2: Token leaked in CLI output or logs (MEDIUM)
- **Attack:** Token printed to stdout/stderr during login or error
- **Mitigation:** Only print "Login successful" on success, never echo the token. Error messages reference token state, not token value.
- **Residual risk:** LOW

### T3: Password visible in terminal during input (MEDIUM)
- **Attack:** Shoulder surfing or terminal recording captures password
- **Mitigation:** Use golang.org/x/term.ReadPassword which disables terminal echo
- **Residual risk:** LOW
</threat_model>
