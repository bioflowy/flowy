    - Test 3: run(["run", "--input", "testdata/inputs.json", "testdata/valid_workflow.wdl"], stdout, stderr) with mock: passes jsonInputs to RunWorkflow
    - Test 4: run(["run", "--task", "my_task", "testdata/valid_workflow.wdl"], stdout, stderr) with mock: calls RunTask instead of RunWorkflow
    - Test 5: run(["run", "--task", "nonexistent", "testdata/valid_workflow.wdl"], stdout, stderr) returns exit 1 (task not found)
    - Test 6: run(["run", "--dir", tempDir, "testdata/valid_workflow.wdl"], stdout, stderr) uses specified dir as execRoot
    - Test 7: run(["run", "--dir", nonEmptyDir, "testdata/valid_workflow.wdl"], stdout, stderr) returns exit 1 (refuses non-empty dir)
    - Test 8: Default exec dir is created under os.TempDir() with "flowy-" prefix
  </behavior>
  <action>
    1. In `cmd/flowy/main.go`, implement `runRun(args []string, stdout, stderr io.Writer) int`:
       - Use `flag.NewFlagSet("run", flag.ContinueOnError)` with `SetOutput(stderr)`.
       - Flags:
         - `--input` (string): JSON input file path.
         - `--task` (string): Named task to run (skip workflow).
         - `--dir` (string): Execution directory.
         - `--path` (string): Import search path.
         - `--verbose` (bool): Print task stdout/stderr.
       - After `fs.Parse(args)`, expect exactly 1 positional arg (WDL file). If missing, return 2.

    2. Parse the WDL file:
       - If `--path` set: `parser.ParseWithSearchPaths(file, nil, []string{pathFlag})`.
       - Otherwise: `parser.Parse(file, nil)`.
       - On parse error: print to stderr, return 1.

    3. Type-check: `checker.Check(doc)`. On errors: print to stderr, return 1.

    4. Load JSON inputs:
       - If `--input` set: read file with `os.ReadFile`, `json.Unmarshal` into `map[string]interface{}`.
       - If not set: use empty map `map[string]interface{}{}`.

    5. Set up execution directory:
       - If `--dir` set: validate that the directory either doesn't exist or is empty. If non-empty, print error and return 1. Create with `os.MkdirAll`.
       - If not set: generate unique dir: `filepath.Join(os.TempDir(), fmt.Sprintf("flowy-%s-%s", time.Now().Format("20060102"), randomHex(4)))`. Create with `os.MkdirAll`.
       - Print `"Execution directory: <path>"` to stderr BEFORE any execution.

    6. Execute:
       - If `--task` set: find task by name in `doc.Tasks`. If not found, print error, return 1. Call `task.RunTask(ctx, taskDef, jsonInputs, runner, execRoot)`.
       - Otherwise: if `doc.Workflows` is empty, print error, return 1. Use `doc.Workflows[0].Name`. Call `workflow.RunWorkflow(ctx, doc, wfName, jsonInputs, runner, execRoot)`.
       - Create runner: `task.NewDockerRunner()` (or `&task.DockerRunner{}` — check the actual constructor).

    7. Handle result:
       - On success: print `"Outputs written to <execRoot>/outputs.json"` to stdout. Return 0.
       - On error: print human-readable error to stderr. Print `"See <execRoot>/error.json for details"` to stderr. Return 1.

    8. For testability, introduce a package-level `var newRunner func() task.ContainerRunner = func() task.ContainerRunner { return &task.DockerRunner{} }` so tests can override with a mock. Alternatively, accept a runner parameter in `runRun` — choose the approach that keeps tests clean without subprocess.

    9. Create test WDL fixtures in `cmd/flowy/testdata/`:
       - `valid_workflow.wdl`: Minimal valid WDL with a workflow and a task (task can use a simple command). For unit tests, the mock runner handles execution.
       - `inputs.json`: Simple JSON input file matching the workflow inputs.
       Tests should use a mock `ContainerRunner` that returns canned `RunResult` — do NOT require Docker in unit tests.

    10. Helper function `randomHex(n int) string`: generate n random bytes, hex-encode them. Use `crypto/rand`.
  </action>
