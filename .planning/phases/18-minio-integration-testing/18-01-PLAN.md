  <name>Task 2: Create S3 round-trip and intermediate file integration tests</name>
  <files>internal/integration/s3_roundtrip_test.go, internal/integration/intermediate_test.go</files>
  <action>
1. Create `internal/integration/s3_roundtrip_test.go` with `//go:build integration` tag:
   - Helper function `newTestBackend(t *testing.T) *storage.S3Backend` that:
     a. Sets `t.Setenv("AWS_ACCESS_KEY_ID", testUser)` and `t.Setenv("AWS_SECRET_ACCESS_KEY", testPassword)`
     b. Constructs `config.Config` with Storage.Type="s3", Storage.Bucket=testBucket, Storage.Endpoint=minioEndpoint, Storage.Region="us-east-1", Storage.MultipartThreshold=100*1024*1024
     c. Calls `storage.NewS3Backend(&cfg)` and returns the backend
   - `TestS3RoundTrip(t *testing.T)`: Upload a file via `backend.UploadFile("test-roundtrip/input.txt", []byte("hello from integration test"))`, download via `backend.DownloadFile("test-roundtrip/input.txt")`, assert content matches exactly.
   - `TestS3StreamRoundTrip(t *testing.T)`: Upload via `backend.UploadFileStream` with a `strings.NewReader`, download via `backend.DownloadFileStream` into a `bytes.Buffer`, assert content matches.
   - `TestS3DirectoryUploadDownload(t *testing.T)`: Create a temp dir with 2-3 files, upload via `backend.UploadDirectory`, download to a different temp dir via `backend.DownloadDirectory`, assert all files present with correct content.
   - `TestS3JSONReadWrite(t *testing.T)`: Write a struct via `backend.WriteJSON`, read it back via `backend.ReadJSON`, assert fields match.

2. Create `internal/integration/intermediate_test.go` with `//go:build integration` tag:
   - `TestIntermediateFile(t *testing.T)`: Simulates the LED pattern end-to-end:
     a. Create S3Backend via `newTestBackend(t)`
     b. Upload an "input" file to S3 at key "runs/test-run/inputs/input.txt" with known content
     c. Download the input file to a local temp dir (simulating localize) via `backend.DownloadFile`
     d. Write input content to local temp file, verify it matches
     e. Create a "mock executor" output: write "processed: " + input content to a local temp file
     f. Upload the output file to S3 at key "runs/test-run/outputs/result.txt" via `backend.UploadFile` (simulating delocalize)
     g. Download from the output key and verify content is "processed: ..." (proves intermediate file passing works)
   - `TestMultipleIntermediateFiles(t *testing.T)`: Same pattern but with 3 input files and 2 output files, verifying all survive the round-trip.

Note: Since `localizeInputs` and `delocalizeOutputs` are unexported daemon functions, we cannot call them directly from the integration package. Instead, we test the same S3Backend operations they use internally (DownloadFile for localize, UploadFile/UploadFileStream for delocalize). This validates the S3 I/O that the LED pattern depends on, against a real MinIO server.
