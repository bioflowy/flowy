wdl/types package will export:

```go
// Type interface — implemented by all 12 concrete type structs
type Type interface {
    TypeName() string       // canonical WDL string, e.g. "Int", "Array[String]?"
    IsOptional() bool       // true if this is T?
    WithOptional(bool) Type // returns immutable copy with optional flag set
}

// Primitives: BooleanType, IntType, FloatType, StringType, FileType, DirectoryType
// Each has: Optional bool
// AnyType has: Optional bool  (AnyType{Optional:true} == None)

// ArrayType has: ItemType Type, Optional bool, Nonempty bool
// MapType has:   KeyType Type, ValType Type, Optional bool
// PairType has:  LeftType Type, RightType Type, Optional bool
// StructType has: Name string, Members map[string]Type, Optional bool
//   NOTE: field is "Name" (not "TypeName") to avoid collision with TypeName() method
```

wdl/values package will export:

```go
// Value interface — implemented by all concrete value structs
type Value interface {
    ValueType() types.Type
}

// Primitives: BooleanValue{Type types.BooleanType; Value bool}
//             IntValue{Type types.IntType; Value int64}
//             FloatValue{Type types.FloatType; Value float64}
//             StringValue{Type types.StringType; Value string}
//             FileValue{Type types.FileType; Value string}      // absolute host path
//             DirectoryValue{Type types.DirectoryType; Value string}  // absolute host path

// NullValue{} — zero-size sentinel; ValueType() returns types.AnyType{Optional:true}

// ArrayValue{Type types.ArrayType; Items []Value}
// MapValue{Type types.MapType; Entries []MapEntry}
// MapEntry{Key Value; Value Value}
// PairValue{Type types.PairType; Left Value; Right Value}
// StructValue{Type types.StructType; Fields map[string]Value}
```
