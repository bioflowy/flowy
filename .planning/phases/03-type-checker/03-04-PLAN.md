<feature>
  <name>Struct literal and field access validation</name>
  <files>wdl/checker/checker.go</files>
  <behavior>
    Pass 1 addition — build structDefs map:
    - Before processing tasks/workflows, iterate doc.Structs and build map[string]*ast.StructDef keyed by StructDef.Name
    - Also build a map[string]types.StructType (structTypes) from each StructDef by converting its Members []*Decl to map[string]types.Type; store in the top-level TypeEnv under the struct name

    checkStructExpr(expr *ast.StructExpr, scope *Scope, structDefs map[string]*ast.StructDef) (types.Type, []*TypeError):
    - Look up expr.TypeName in structDefs; if not found, return TypeError: "undefined struct %q"
    - Build set of provided field names from expr.Members
    - For each member in the StructDef.Members: check it exists in expr.Members; if missing, TypeError: "struct %q missing field %q"
    - For each member in expr.Members: check it exists in the StructDef; if unknown, TypeError: "struct %q has no field %q"
    - For each matching field: determine value type (literal type or scope lookup for IdentExpr); if Coerces(valueType, fieldType) is false, TypeError: "field %q: cannot use %s where %s is expected"
    - On success, return types.StructType{Name: expr.TypeName, Members: <field types from def>} (deep-copy Members per research warning)

    checkGetExpr(expr *ast.GetExpr, scope *Scope, structDefs map[string]*ast.StructDef) (types.Type, *TypeError):
    - Resolve the base expression type: for IdentExpr base, look up in scope
    - Type-assert to types.StructType; if not a struct type, TypeError: "field access on non-struct type %s"
    - Look up expr.Field in structType.Members; if not found, TypeError: "struct %q has no field %q"
    - Return the field's types.Type

    Integration into Check() pass 2:
    - When evaluating a Decl.Expr: add type-switch cases for *ast.StructExpr (call checkStructExpr) and *ast.GetExpr (call checkGetExpr)
    - Append returned TypeErrors to the accumulated errors slice
    - Return the resolved type for use in type mismatch check against decl.Type

    Edge cases:
    - A StructExpr where all fields are provided and typed correctly — no errors, returns StructType
    - A GetExpr on None (NullLit) — treat as any type, no error (deferred to Phase 4 runtime)
  </behavior>
