  <files>wdl/checker/coerce.go, wdl/checker/promote.go, wdl/checker/checker_test.go</files>
  <behavior>
    Coerces(from, to types.Type) bool — 6 WDL 1.2 shallow rules:
    Rule 1: T→T? — if to.IsOptional() and !from.IsOptional(), recurse with to.WithOptional(false)
    Rule 2: Int→Float — IntType to FloatType (optional-stripped versions must match after Rule 1 applied)
    Rule 3a: String→File
    Rule 3b: String→Directory
    Rule 4: File→String
    Rule 5: Array[T]+→Array[T] — ArrayType with Nonempty:true coerces to ArrayType with same item type and Nonempty:false (item types NOT compared, shallow only)
    Rule 6: if from==to (same TypeName and same optional flag), return true (identity)
    All other combinations: return false

    optionalize(t types.Type) types.Type:
    - If t.IsOptional() == true, return t unchanged (idempotency guard)
    - Otherwise return t.WithOptional(true)

    arrayize(t types.Type) types.Type:
    - Return types.ArrayType{ItemType: t}

    Test cases in TestCoerces (from checker_test.go stub):
    - Coerces(IntType{}, FloatType{}) → true
    - Coerces(StringType{}, FileType{}) → true
    - Coerces(StringType{}, DirectoryType{}) → true
    - Coerces(FileType{}, StringType{}) → true
    - Coerces(IntType{}, IntType{Optional:true}) → true
    - Coerces(ArrayType{ItemType:IntType{},Nonempty:true}, ArrayType{ItemType:IntType{},Nonempty:false}) → true
    - Coerces(StringType{}, IntType{}) → false
    - Coerces(ArrayType{ItemType:StringType{}}, ArrayType{ItemType:FileType{}}) → false (shallow — no item check)

    - optionalize(IntType{Optional:true}) → IntType{Optional:true} (unchanged, not wrapped)
