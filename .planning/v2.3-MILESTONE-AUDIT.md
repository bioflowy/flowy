## Cross-Phase Integration

Cross-phase wiring was audited directly against the shipped code and passing tests.

### Verified Integrations

1. **Phase 41 → Phase 42**
   Label evaluation happens during workflow output auto-registration, and the resulting managed-file record is persisted together with `source_type = workflow` and `run_id`.

2. **Phase 42 → Phase 43**
   The Files API returns `label`, `source_type`, and optional `run_id`; the Files tab consumes that metadata to render label-first rows, source badges, and conditional run navigation.

3. **Phase 42 → Run navigation**
   Workflow-generated rows expose provenance strongly enough for the Files tab to navigate to `/projects/:slug/runs/:run_id`, while imported/uploaded rows omit the run link.

4. **Phase 41 + 43 → Workflow launch UX**
   The managed-file picker remains path-backed for execution semantics, but renders label-first UI and preserves manual path entry for backward compatibility.

### Integration Result

No broken contract was found between backend storage/API changes and frontend consumption. No cross-phase blocker was identified.
