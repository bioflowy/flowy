    1. Create `internal/store/sqlite/migrations/00001_init.sql`:
       - `-- +goose Up` section creates runs and tasks tables with all columns per RESEARCH.md
       - runs: id TEXT PK, wdl_path TEXT NOT NULL, inputs_json TEXT NOT NULL, state TEXT NOT NULL DEFAULT 'PENDING', created_at DATETIME NOT NULL DEFAULT (datetime('now')), updated_at DATETIME NOT NULL DEFAULT (datetime('now'))
       - tasks: id INTEGER PRIMARY KEY AUTOINCREMENT, run_id TEXT NOT NULL REFERENCES runs(id), task_name TEXT NOT NULL, state TEXT NOT NULL DEFAULT 'PENDING', shard_index INTEGER NOT NULL DEFAULT 0, daemon_id TEXT, last_heartbeat_at DATETIME, created_at DATETIME NOT NULL DEFAULT (datetime('now')), updated_at DATETIME NOT NULL DEFAULT (datetime('now'))
       - Indexes: idx_tasks_run_id on tasks(run_id), idx_tasks_state on tasks(state)
       - `-- +goose Down` drops tasks then runs

    2. Create `internal/store/sqlite/sqlite.go`:
       - `//go:embed migrations/*.sql` for embedMigrations
       - `Open(dsn string) (*SQLiteStore, error)`:
         - sql.Open("sqlite", dsn) for writer, SetMaxOpenConns(1)
         - sql.Open("sqlite", dsn) for reader (no MaxOpenConns limit)
         - goose.SetBaseFS(embedMigrations), goose.SetDialect("sqlite3") — NOT "sqlite"
         - goose.Up(writer, "migrations")
         - Return &SQLiteStore{writer, reader}
       - `Close() error` closes both pools
       - `var _ store.Store = (*SQLiteStore)(nil)` — compile-time interface check
       - For tests: provide `OpenMemory() (*SQLiteStore, error)` that uses "file::memory:?cache=shared&_pragma=journal_mode(WAL)&_pragma=foreign_keys(ON)" DSN

    3. Create `internal/store/sqlite/runs.go`:
       - CreateRun: INSERT INTO runs (id, wdl_path, inputs_json, state) VALUES (?, ?, ?, ?)
       - GetRun: SELECT * FROM runs WHERE id = ?
       - GetRunByPrefix: SELECT * FROM runs WHERE id LIKE ? — append '%' to prefix. If count > 1, return error "ambiguous run ID prefix: N matches". If count == 0, return error "run not found".
       - UpdateRunState: UPDATE runs SET state = ?, updated_at = datetime('now') WHERE id = ?

    4. Create `internal/store/sqlite/tasks.go`:
       - CreateTask: INSERT INTO tasks (run_id, task_name, shard_index) VALUES (?, ?, ?)
       - ListTasksByRun: SELECT * FROM tasks WHERE run_id = ? ORDER BY id
       - ClaimTask(ctx, daemonID): Atomic single UPDATE:
         ```sql
         UPDATE tasks SET state = 'CLAIMED', daemon_id = ?, last_heartbeat_at = datetime('now'), updated_at = datetime('now')
         WHERE id = (SELECT id FROM tasks WHERE state = 'PENDING' ORDER BY id LIMIT 1)
         RETURNING id, run_id, task_name, shard_index
         ```
         Use writer connection. If no rows affected, return nil, nil (no task available).
       - UpdateTaskState: UPDATE tasks SET state = ?, updated_at = datetime('now') WHERE id = ?
       - UpdateHeartbeat: UPDATE tasks SET last_heartbeat_at = datetime('now'), updated_at = datetime('now') WHERE id = ?
       - FindStaleTasks(ctx, timeoutSec):
         Build modifier string: `fmt.Sprintf("-%d seconds", timeoutSec)`
         Query: `SELECT ... FROM tasks WHERE state IN ('CLAIMED', 'RUNNING') AND last_heartbeat_at < datetime('now', ?) ORDER BY id`
         IMPORTANT: Use string modifier, not integer — SQLite datetime() requires string.

       - For TestFindStaleTasks: insert tasks, then manually UPDATE last_heartbeat_at to a past time to simulate staleness
       - For TestClaimTaskAtomicNoRace: use goroutines with sync.WaitGroup, verify exactly one got a task
