  <name>Task 2: Submit handler, dispatch logic, abort handler, and stale detection</name>
  <files>internal/server/dispatch.go, internal/server/handlers.go, internal/server/server.go, internal/server/server_test.go</files>
  <behavior>
    - POST /workflows with valid WDL path + inputs returns 201 with run_id, run exists in DB as PENDING initially
    - POST /workflows with empty wdl_path returns 400
    - POST /workflows with invalid WDL path returns 400 with parse error
    - POST /workflows/{id}/abort on a running workflow returns 200 with ABORTED state
    - POST /workflows/{id}/abort on nonexistent/completed run returns 404
    - dispatchFn creates a task row in SQLite, writes inputs.json to per-task dir, then polls until task completes
    - waitForTask returns outputs when task reaches COMPLETED, error on FAILED/ABORTED
    - waitForTask respects context cancellation
    - Stale detection resets stale tasks to PENDING
    - Run goroutine logs warning when task unclaimed for >5 minutes
  </behavior>
  <action>
1. Create internal/server/dispatch.go:
   - `func (s *Server) makeDispatchFn(runID string) workflow.TaskDispatchFn` — returns a closure that:
     a. Computes taskDir via `store.TaskDir(s.cfg.BaseDir, runID, t.Name, 0)` (shardIndex 0 for non-scatter; scatter support will need to be determined from the call context — use 0 as default for now, the scheduler handles scatter iteration).
     b. Creates task directory via `store.CreateTaskDirs(...)`.
     c. Serializes inputs to `filepath.Join(taskDir, "inputs.json")` as JSON.
     d. Creates a Task record: `&storemod.Task{RunID: runID, TaskName: t.Name, ShardIndex: 0}`.
     e. Calls `s.store.CreateTask(ctx, task)`.
     f. Calls `s.waitForTask(ctx, task.ID, runID, t.Name)` — blocks until daemon completes.
     g. Returns the outputs from waitForTask.

   - `func (s *Server) waitForTask(ctx context.Context, taskID int64, runID, taskName string) (map[string]values.Value, error)`:
     a. `time.NewTicker(2 * time.Second)` poll loop.
     b. On each tick: `s.store.GetTaskByID(ctx, taskID)`.
     c. If COMPLETED: call `loadTaskOutputs(s.cfg.BaseDir, runID, taskName, task.ShardIndex)` and return.
     d. If FAILED: return error with task name.
     e. If ABORTED: return context.Canceled error.
     f. On ctx.Done(): return ctx.Err().
     g. Log warning if task has been PENDING for >5 minutes (track start time, check on each tick).

   - `func loadTaskOutputs(baseDir, runID, taskName string, shardIndex int) (map[string]values.Value, error)`:
     a. Read `outputs.json` from `store.TaskDir(baseDir, runID, taskName, shardIndex)`.
     b. Parse JSON into `map[string]interface{}`.
     c. Convert each value to `values.Value` using appropriate conversion (string -> values.StringValue, int -> values.IntValue, etc.). For Phase 10, a simple conversion that handles string/int/float/bool is sufficient — complex WDL types will be refined in Phase 11 integration testing.
     d. Return the map.

   - `func (s *Server) runWorkflow(ctx context.Context, runID string, doc *ast.Document, inputs map[string]interface{})`:
     a. `defer s.wg.Done()` (s.wg.Add(1) is called before the goroutine launch in handleSubmit).
     b. Transition run to RUNNING: `s.store.UpdateRunState(ctx, runID, store.RunRunning)`.
     c. Determine workflow name: use first workflow in doc.Workflows (single-workflow WDL files are the standard case).
     d. Set execRoot to `filepath.Join(s.cfg.BaseDir, "runs", runID)`.
     e. Call `workflow.RunWorkflowWithDispatch(ctx, doc, wfName, inputs, nil, execRoot, s.makeDispatchFn(runID))`. Pass nil for runner — the dispatch model does not use Docker locally.
     f. On success: conditional update `UpdateRunState(ctx, runID, store.RunCompleted)` — use a new store method or check current state first to avoid COMPLETED overwriting ABORTED. For simplicity, call UpdateRunState and accept that if already ABORTED, the UPDATE is a no-op (the SQL in Phase 9 does `UPDATE runs SET state = ? WHERE id = ?` unconditionally — for the ABORTED race, check `ctx.Err()` first: if ctx was cancelled, skip the COMPLETED transition).
     g. On error: if ctx.Err() != nil (abort), do nothing (abort handler already set ABORTED). Otherwise set FAILED.
     h. Clean up: `s.mu.Lock(); delete(s.runs, runID); s.mu.Unlock()`.
