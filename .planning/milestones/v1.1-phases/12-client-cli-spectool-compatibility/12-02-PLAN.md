<objective>
Add submit, status, and outputs subcommands to the flowy CLI binary, including local file staging to the shared filesystem.

Purpose: These three subcommands are the user-facing API for interacting with distributed workflows. The submit command must copy local input files to the shared filesystem before sending the request to the server — this is the critical path for multi-host execution where clients and daemons are on different machines.

Output: Extended cmd/flowy/main.go with three new subcommands and comprehensive tests.

1. **Update the switch in `run()` function** in `cmd/flowy/main.go` to add three new cases:
   ```go
   case "submit":
       return runSubmit(args[1:], stdout, stderr)
   case "status":
       return runStatus(args[1:], stdout, stderr)
   case "outputs":
       return runOutputs(args[1:], stdout, stderr)
   ```
   Also update the `usage()` function to list the new subcommands.

2. **Add `loadConfigOptional` helper** — loads config from `--config` flag path, falls back to `./flowy.yaml`, falls back to `config.Default()`. Used by all server-facing subcommands.

3. **Add `resolveServerURL` helper** — returns `--server` flag value if set, else `cfg.Client.ServerURL`. Used by all server-facing subcommands.

4. **Implement `runSubmit(args, stdout, stderr) int`:**
   - Parse flags: `--input` / `-i` (JSON inputs file), `--server` (server URL override), `--config` (config path), `--path` (import search dir)
   - Use `reorderArgs` for spectool compatibility (flags after positional args)
   - Validate: exactly one positional arg (WDL file path)
   - Load config via `loadConfigOptional`, resolve server URL
   - Generate UUID via `uuid.New().String()` as run ID
   - Call `store.CreateRunDirs(baseDir, runID)` to create staging dirs
   - **Stage WDL file:** resolve to absolute path via `filepath.Abs`. If the absolute path is NOT under `cfg.BaseDir` (use `strings.HasPrefix` after resolving both to absolute), copy WDL to `store.RunInputsDir(baseDir, runID) + "/workflow.wdl"` using `io.Copy`
   - **Stage input files:** read inputs JSON, iterate over all string values in the map. For each string: resolve to absolute path, check `os.Stat` — if file exists AND path is NOT already under `cfg.BaseDir`, copy to `store.RunInputsDir(baseDir, runID)` preserving filename via `filepath.Base`, update the map value with the new staged path
   - Build `api.SubmitRequest{RunID: runID, WDLPath: stagedWDLPath, InputsJSON: updatedInputs, SearchPaths: searchPaths}`
   - Create `client.New(serverURL)`, call `Submit(ctx, req)`
   - On error: clean up staged dirs via `os.RemoveAll(filepath.Join(baseDir, "runs", runID))`, print error to stderr, return 1
   - On success: print `resp.RunID` to stdout (just the UUID + newline), return 0

5. **Implement `runStatus(args, stdout, stderr) int`:**
   - Parse flags: `--server`, `--config`
   - Validate: exactly one positional arg (run ID or prefix)
   - Create client, call `Status(ctx, runID)`
   - Print `resp.State` to stdout (plain string + newline), return 0
   - On error: print to stderr, return 1

6. **Implement `runOutputs(args, stdout, stderr) int`:**
   - Parse flags: `--server`, `--config`, `--output` (write JSON to file instead of stdout)
   - Validate: exactly one positional arg (run ID or prefix)
   - Create client, call `Outputs(ctx, runID)`
   - On success: marshal `resp.Outputs` as indented JSON, write to stdout or `--output` file
   - On error: if error contains "not yet completed" or similar, print friendly message; else print error. Return 1

7. **Add `stageInputFiles` helper function** — extracted for testability:
   ```go
   func stageInputFiles(inputs map[string]interface{}, inputsDir, baseDir string) (map[string]interface{}, error)
   ```
   Returns a new map with staged paths replacing local paths. Only stages string values that (a) resolve to an existing file via `os.Stat`, and (b) whose absolute path is NOT already under `baseDir`. Uses `io.Copy` for copying.

8. **Add `stageFile` helper** — copies a single file to destDir, returns the new path:
   ```go
   func stageFile(srcPath, destDir string) (string, error)
   ```

9. **Update `reorderArgs`** to include the new flags in `knownValueFlags`: `--server`, `--config`, `-server`, `-config`.
