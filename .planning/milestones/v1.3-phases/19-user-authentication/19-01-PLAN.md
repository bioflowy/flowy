1. Create `internal/store/sqlite/migrations/00004_users.sql`:
   ```sql
   -- +goose Up
   CREATE TABLE IF NOT EXISTS users (
       id            TEXT     PRIMARY KEY,
       username      TEXT     NOT NULL UNIQUE,
       password_hash TEXT     NOT NULL,
       display_name  TEXT     NOT NULL DEFAULT '',
       email         TEXT     NOT NULL DEFAULT '',
       global_role   TEXT     NOT NULL DEFAULT 'user',
       is_active     INTEGER  NOT NULL DEFAULT 1,
       created_at    DATETIME NOT NULL DEFAULT (datetime('now')),
       updated_at    DATETIME NOT NULL DEFAULT (datetime('now'))
   );
   CREATE INDEX IF NOT EXISTS idx_users_username ON users(username);

   CREATE TABLE IF NOT EXISTS server_config (
       key   TEXT PRIMARY KEY,
       value TEXT NOT NULL
   );

   -- +goose Down
   DROP TABLE IF EXISTS server_config;
   DROP TABLE IF EXISTS users;
   ```

   - `GetUserByID`: SELECT WHERE id = ?

   - `DeactivateUser`: UPDATE is_active = 0, updated_at = now WHERE id = ?
   - `CountUsers`: SELECT COUNT(*) FROM users
   - For is_active, store as INTEGER (1/0) in SQLite, convert to bool in Go
