  <action>
Replace the five stub methods in `internal/server/handlers_registry.go` with full implementations:

**handleRegistryTag** (POST /projects/{slug}/registry/{name}/tags) — admin only:
- Extract project via `projectFromContext(r.Context())`
- Get `name` from `chi.URLParam(r, "name")`
- Decode `api.RegistryTagRequest` from body
- Validate `req.Tag` with `validTagName(req.Tag)` — return 400: `"invalid tag name: must be 1-128 chars, no '@' or ':'"`
- Validate `req.Digest` is not empty — return 400: `"digest is required"`
- Look up entry: `s.store.GetRegistryEntry(r.Context(), proj.ID, name)` — return 404: `fmt.Sprintf("entry %q not found", name)`
- Look up version by digest: `s.store.GetRegistryVersionByDigest(r.Context(), proj.ID, name, req.Digest)` — return 404: `fmt.Sprintf("version with digest %q not found for entry %q", req.Digest, name)`
- Upsert tag: `s.store.UpsertRegistryTag(r.Context(), entry.ID, req.Tag, version.ID)` — return 500 on error
- Response 200: `map[string]string{"tag": req.Tag, "digest": req.Digest, "entry": name}`

**handleRegistryDeleteTag** (DELETE /projects/{slug}/registry/{name}/tags/{tag}) — admin only:
- Extract project, get `name` from URL, get `tag` from `chi.URLParam(r, "tag")`
- Look up entry: `s.store.GetRegistryEntry(r.Context(), proj.ID, name)` — return 404 if not found
- Delete tag: `s.store.DeleteRegistryTag(r.Context(), entry.ID, tag)` — return 404 if error (tag not found)
- Response 204 No Content (no body): `w.WriteHeader(http.StatusNoContent)`

**handleRegistryList** (GET /projects/{slug}/registry) — viewer:
- Extract project
- Call `s.store.ListRegistryEntries(r.Context(), proj.ID)`
- Map each `store.RegistryEntryListItem` to `api.RegistryEntryResponse`:
  - `Name: item.Name`
  - `Kind: item.Kind`
  - `VersionCount: item.VersionCount`
  - `Tags: item.Tags` (if nil, use empty slice `[]string{}` to avoid null in JSON)
  - `CreatedAt: item.CreatedAt.Format("2006-01-02T15:04:05Z")`
- Response 200: JSON array of `api.RegistryEntryResponse`

**handleRegistryListVersions** (GET /projects/{slug}/registry/{name}/versions) — viewer:
- Extract project, get `name` from URL
- Call `s.store.ListRegistryVersions(r.Context(), proj.ID, name)` — return 404 if error (entry not found)
- Map each `store.RegistryVersionListItem` to `api.RegistryVersionResponse`:
  - `ID: item.ID`
  - `Digest: item.Digest`
  - `Tags: item.Tags` (if nil, use `[]string{}`)
  - `CreatedAt: item.CreatedAt.Format("2006-01-02T15:04:05Z")`
- Response 200: JSON array of `api.RegistryVersionResponse`

**handleRegistryDelete** (DELETE /projects/{slug}/registry/{name}) — admin only:
- Extract project, get `name` from URL
- Call `s.store.DeleteRegistryEntry(r.Context(), proj.ID, name)` — return 404 if error
- Response 204 No Content: `w.WriteHeader(http.StatusNoContent)`
