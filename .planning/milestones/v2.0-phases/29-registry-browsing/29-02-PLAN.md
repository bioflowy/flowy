- Reset form on dialog open change when closing

```
<div className="p-6">
```

State management:
- `const { slug, name } = useParams<{ slug: string; name: string }>()`
- `const { data: versions, isLoading: versionsLoading } = useRegistryVersions(slug!, name!)`
- `const [selectedDigest, setSelectedDigest] = useState<string>('')`
- Use `useEffect` to set `selectedDigest` to `versions?.[0]?.digest ?? ''` when versions data loads (NOT in useState initializer since versions is async)
- `const { data: content, isLoading: contentLoading, isError: contentError } = useRegistryContent(slug!, name!, selectedDigest)`
- Admin detection: same pattern as RegistryPage — `useProjectMembers(slug!)` + `useAuthStore((s) => s.username)` + `currentMember?.role === 'admin'`
- Dialog state: `const [createTagOpen, setCreateTagOpen] = useState(false)` and `const [deleteTagName, setDeleteTagName] = useState<string | null>(null)`

Version table columns: Digest, Tags, Created, (tag actions `w-[50px]`)

Version row rendering:
- `<TableRow key={v.id} className={v.digest === selectedDigest ? 'bg-muted/50 cursor-pointer' : 'cursor-pointer hover:bg-muted/50'} onClick={() => setSelectedDigest(v.digest)}>`
- Digest cell: `truncateDigest(v.digest)` — helper function: `if (digest.startsWith('sha256:')) return \`sha256:${digest.slice(7, 23)}...\``
- Tags cell: map `v.tags` to `<Badge variant="outline" key={tag} className="mr-1">{tag}</Badge>`. If no tags, show `"\u2014"` (em dash).
- Created cell: `formatDate(v.created_at)` — same helper as RegistryPage
- Actions cell (admin only): For each tag on the version, show a small trash icon button `<Button variant="ghost" size="icon" className="h-7 w-7" onClick={(e) => { e.stopPropagation(); setDeleteTagName(tag) }} aria-label={\`Delete tag ${tag}\`}>`. If version has no tags AND user is admin, cell is empty.

Loading state for versions: 3 skeleton rows (`data-testid="skeleton-row"`), cells with `h-4 w-{N} animate-pulse rounded bg-muted`.

Empty versions state: Single row colSpan={4}: `"No versions found."`

WDL content loading: `<div className="h-[200px] animate-pulse rounded bg-muted" data-testid="source-skeleton" />`
WDL content error: `<p className="text-muted-foreground">Failed to load source for this version.</p>`

Kind badge display below h1: Same badge component as RegistryPage — `<Badge variant="outline" className={...}>{kind}</Badge>` where kind comes from `content?.kind` or from a separate entry detail query. Since versions don't have kind, use the content response. Show "Loading..." as text-muted-foreground when content hasn't loaded yet. Alternatively, pass kind via `useRegistryContent` — the `RegistryPullResponse` has a `kind` field.

Dialogs at bottom of component:
- `<CreateTagDialog open={createTagOpen} onOpenChange={setCreateTagOpen} slug={slug!} name={name!} versions={versions ?? []} />`
- `<DeleteTagDialog open={!!deleteTagName} onOpenChange={(open) => { if (!open) setDeleteTagName(null) }} slug={slug!} entryName={name!} tagName={deleteTagName} />`
