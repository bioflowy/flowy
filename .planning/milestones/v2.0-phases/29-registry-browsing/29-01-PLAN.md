**1. Create `web/src/features/registry/useRegistry.ts`** with all React Query hooks following the `useUsers.ts` pattern:

Export these TypeScript interfaces:
- `RegistryEntryResponse` with fields: `name: string`, `kind: string`, `version_count: number`, `tags: string[]`, `created_at: string`
- `RegistryVersionResponse` with fields: `id: string`, `digest: string`, `tags: string[]`, `created_at: string`
- `RegistryPullResponse` with fields: `name: string`, `digest: string`, `kind: string`, `content: string`

Export these hooks:
- `useRegistryEntries(slug: string)` — `GET /projects/${slug}/registry`, queryKey `['projects', slug, 'registry']`, `enabled: !!slug`
- `useRegistryVersions(slug: string, name: string)` — `GET /projects/${slug}/registry/${name}/versions`, queryKey `['projects', slug, 'registry', name, 'versions']`, `enabled: !!slug && !!name`
- `useRegistryContent(slug: string, name: string, digest: string)` — `GET /projects/${slug}/registry/${name}?digest=${encodeURIComponent(digest)}`, queryKey `['projects', slug, 'registry', name, 'content', digest]`, `enabled: !!slug && !!name && !!digest`
- `useDeleteRegistryEntry(slug: string)` — mutation calling `apiClient.delete(/projects/${slug}/registry/${name})`, onSuccess invalidates `['projects', slug, 'registry']`
- `useUpsertTag(slug: string, name: string)` — mutation calling `apiClient.post(/projects/${slug}/registry/${name}/tags, { tag, digest })`, onSuccess invalidates both `['projects', slug, 'registry']` and `['projects', slug, 'registry', name, 'versions']`
- `useDeleteTag(slug: string, name: string)` — mutation calling `apiClient.delete(/projects/${slug}/registry/${name}/tags/${tag})`, onSuccess invalidates both `['projects', slug, 'registry']` and `['projects', slug, 'registry', name, 'versions']`

- Cancel button text: `"Keep Entry"` (AlertDialogCancel wrapping Button variant="outline")
- Confirm button: `"Delete"` with `className="bg-destructive text-destructive-foreground hover:bg-destructive/90"`. Uses `useDeleteRegistryEntry(slug!)` mutation. On success: `toast.success(\`${deleteEntry} deleted.\`)` and close dialog. On error: `toast.error('Something went wrong. Please try again.')`.
- Show Loader2 spinner during deletion (same pattern as ProjectDetailPage).

Loading state: 4 skeleton rows with `data-testid="skeleton-row"`. Each row has 6 cells. Each data cell: `<div className="h-4 w-{N} animate-pulse rounded bg-muted" />` with widths w-24, w-16, w-12, w-32, w-20.

Empty state: Single row with `colSpan={6}` and `className="text-center text-muted-foreground"`. Text: `"No registry entries."` followed by `<p className="text-xs text-muted-foreground mt-1">Push a WDL workflow or task using the flowy CLI to see it here.</p>`.

Error state: If `isError` is true on the query, render single row colSpan={6}: `"Failed to load registry. Please refresh the page."`.
