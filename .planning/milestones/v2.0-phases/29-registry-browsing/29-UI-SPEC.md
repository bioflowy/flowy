## Typography

Consistent with established Phase 26–28 patterns verified from UsersPage.tsx and ProjectDetailPage.tsx:

| Role | Size | Weight | Line Height | Tailwind Class | Usage |
|------|------|--------|-------------|----------------|-------|
| Body | 14px (text-sm) | 400 (regular) | 1.5 | `text-sm` | Table cell content, dialog labels, muted descriptions |
| Label | 14px (text-sm) | 500 (medium) | 1.5 | `text-sm font-medium` | Form field labels, table column headers |
| Heading | 20px (text-xl) | 600 (semibold) | 1.2 | `text-xl font-semibold` | Page h1 ("Registry"), section h2 ("Versions", "Source") |
| Caption | 12px (text-xs) | 400 (regular) | 1.4 | `text-xs text-muted-foreground` | Slug subtitles, WDL line numbers, helper text |

Exactly 4 sizes declared. Exactly 2 intentional weights (400 and 600). Weight 500 is a shadcn/ui Table component default — it is applied automatically by the `TableHead` component via its built-in `font-medium` class. Executors must not apply weight 500 as a deliberate design choice outside of `TableHead` cells; it should never appear in custom components or new UI elements.

Code/monospace exception: WDL source viewer uses `font-mono text-sm` (14px monospace) — this is a display variant of the Body role, not a fifth size.

## Page Structure

### Page 1: Registry List — `/projects/:slug/registry`

Primary visual anchor: h1 "Registry" heading — users orient to the page title first, then scan the table downward.

Layout mirrors UsersPage.tsx exactly:

```
<div className="p-6">
  <div className="flex items-center justify-between">
    <h1 className="text-xl font-semibold">Registry</h1>
    {/* No primary CTA — registry entries created via CLI only */}
  </div>
  <div className="mt-8">
    <Table>
      <TableHeader> Name | Kind | Versions | Tags | Created | (actions col) </TableHeader>
      <TableBody>
        {isLoading → 4 skeleton rows}
        {empty → single colspan row with empty state copy}
        {data → entry rows with click navigation + admin three-dot menu}
      </TableBody>
    </Table>
  </div>
</div>
```

Row interaction: entire `<TableRow>` is clickable (`cursor-pointer hover:bg-muted/50`), navigates to entry detail. Three-dot dropdown uses `e.stopPropagation()` to prevent row navigation conflict.

Admin gating: `isProjectAdmin` derived from `useProjectMembers` + `authStore.username` comparison (Phase 28 pattern). Three-dot dropdown column only renders when `isProjectAdmin === true`.

### Page 2: Registry Entry Detail — `/projects/:slug/registry/:name`

Two-section layout:

```
<div className="p-6">
  <h1 className="text-xl font-semibold">{name}</h1>     ← entry name
  <p className="text-xs text-muted-foreground">...</p>  ← kind badge + version count

  {/* Section: Versions */}
  <div className="mt-8">
    <div className="flex items-center justify-between">
      <h2 className="text-xl font-semibold">Versions</h2>
      {isProjectAdmin && <Button onClick={openCreateTag}>Create Tag</Button>}
    </div>
    <Table>
      <TableHeader> Digest | Tags | Created | (tag actions col) </TableHeader>
      <TableBody>
        {version rows — selected row highlighted with bg-muted/50 ring}
      </TableBody>
    </Table>
  </div>

  <Separator className="my-6" />

  {/* Section: Source */}
  <div>
    <h2 className="text-xl font-semibold">Source</h2>
    <p className="text-xs text-muted-foreground mt-1">
      {truncateDigest(selectedDigest)}
    </p>
    <div className="mt-4">
      <WDLSourceViewer content={content} />
    </div>
  </div>
</div>
```

Selected version state: `useState<string>` initialized to `versions?.[0]?.digest`. Clicking a version row sets selected digest. Selected row gets `bg-muted/50` visual indicator.

## Interaction States

| State | Visual Treatment |
|-------|-----------------|
| Table loading | 4 skeleton rows: `<div className="h-4 w-N animate-pulse rounded bg-muted" />` per cell |
| Table empty | Single full-width row: `className="text-center text-muted-foreground"` |
| Table error | Single full-width row with error copy (see Copywriting) |
| Version row selected | `className="bg-muted/50"` on the TableRow |
| WDL content loading | WDLSourceViewer shows skeleton: single full-width `<div className="h-[200px] animate-pulse rounded bg-muted" />` |
| Copy button clicked | Icon swaps from Copy to Check for 2000ms, then reverts |
| Dialog loading (mutation pending) | Submit button disabled + shows loading text |
| Tag creation success | Sonner toast: `toast.success(...)`, dialog closes |
| Tag deletion success | Sonner toast: `toast.success(...)`, AlertDialog closes |
| Entry deletion success | Sonner toast: `toast.success(...)`, navigate back to registry list |
| Mutation error | Sonner toast: `toast.error(...)` |

## Validation Schema

Tag creation form (zod):
```typescript
const tagSchema = z.object({
  tag: z.string().min(1, 'Tag name is required').max(128).refine(
    (v) => !v.includes('@') && !v.includes(':'),
    { message: "Tag must not contain '@' or ':'" }
  ),
  digest: z.string().min(1, 'Select a version'),
})
```

Field error messages appear as `FormMessage` below each field — shadcn/ui form pattern.
