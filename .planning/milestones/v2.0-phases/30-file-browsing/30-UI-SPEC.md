## Interaction Contracts

### RunsPage (`/projects/:slug/runs`)

**Layout:** `<div className="p-6">` outer wrapper — matches all Phase 27-29 pages exactly.

**Page header:** `<h1 className="text-xl font-semibold">Runs</h1>` — no action button (read-only list).

**Table header:** Table appears at `mt-8` below the page header.

**Columns:** Run ID (truncated UUID, 8 chars), Status (badge), Registry Ref / WDL Path, Started (formatted date), Duration.

**Run ID display:** Show first 8 characters of UUID. Wrap in `<Tooltip>` showing full UUID on hover. Use `font-mono text-sm` for the truncated ID cell.

**Duration formatting:** Calculate from `created_at` to `updated_at`. Format as human-readable string:
- Under 60 seconds: `{N}s`
- Under 60 minutes: `{M}m {S}s`
- 60 minutes or more: `{H}h {M}m`
- For `Running` state: calculate from `created_at` to current time, append no suffix (duration is elapsed)
- For `Pending` state: show `—`

**Registry Ref / WDL Path column:** Display `registry_ref` if non-empty, else display `wdl_path`. Truncate to 40 characters with `…` if longer.

**Row click:** Navigate to `/projects/${slug}/runs/${run.id}` — full cursor-pointer row, `hover:bg-muted/50`.

**Loading state:** 5 skeleton rows, one `animate-pulse rounded bg-muted` div per column cell.

**Empty state:** Single row spanning all 5 columns, `text-center text-muted-foreground`.
- Heading cell: "No runs yet."
- Sub-line `<p className="text-xs text-muted-foreground mt-1">`: "Submit a workflow using the flowy CLI to see runs here."

**Error state:** Single row spanning all columns.
- Copy: "Failed to load runs. Please refresh the page."
- Class: `text-center text-muted-foreground`

### RunDetailPage (`/projects/:slug/runs/:id`)

**Layout:** `<div className="p-6">` outer wrapper.

**Section 1 — Metadata header:**

```
<h1 className="text-xl font-semibold">{truncated run ID} <Tooltip>full UUID</Tooltip></h1>
<div className="text-xs text-muted-foreground mt-1 flex items-center gap-2">
  <StatusBadge state={run.state} />
  <span>{formatted start time}</span>
  <span>{duration or "—"}</span>
</div>
<div className="text-xs text-muted-foreground mt-1">
  {registry_ref or wdl_path label}
</div>
```

Metadata fields displayed:
- Run ID (full, `font-mono text-sm` in a `<p>` below the heading)
- Status badge
- Registry ref or WDL path
- Started: formatted date+time (`toLocaleString('en-US', { dateStyle: 'medium', timeStyle: 'short' })`)
- Ended: same format, or "—" if not completed
- Duration: same format as runs list

**Section 2 — Outputs:**

Separated from metadata by `<Separator className="my-6" />`.

`<h2 className="text-xl font-semibold">Outputs</h2>` at `mt-0` (Separator provides spacing).

**When run state is not COMPLETED:** Show message below the h2:
```
<p className="text-muted-foreground text-sm mt-4">
  Outputs are available once the run has completed.
  {state === 'RUNNING' && ' This run is currently in progress.'}
  {state === 'FAILED' && ' This run failed — check CLI logs for details.'}
  {state === 'PENDING' && ' This run is queued.'}
</p>
```
No outputs table is rendered.

**When run state is COMPLETED and outputs loading:** Show `<div className="h-[200px] animate-pulse rounded bg-muted mt-4" />`.

**When run state is COMPLETED and outputs loaded:** Render outputs table at `mt-4`.

Outputs table columns: Output Name (WDL key), Type, Value / Action.

**File-type output row:**
- Output Name cell: WDL output key (e.g. `task.output_file`)
- Type cell: `<Badge variant="outline" className="border-slate-300 text-slate-600 bg-slate-50">File</Badge>`
- Value/Action cell: filename (last path segment), plus `<Button size="sm" variant="default" className="ml-2">Download</Button>`
- Below the row (when preview expanded): code block — see Inline Preview section

**Primitive output row:**
- Output Name cell: WDL output key
- Type cell: type inferred from value (`string`, `int`, `float`, `boolean`, `array`) — display as `<span className="text-xs text-muted-foreground">{type}</span>`
- Value/Action cell: value displayed as `<code className="text-sm font-mono">{String(value)}</code>`. Arrays rendered as comma-separated values.

**File detection heuristic:** A value is treated as File if it is a `string` AND matches any of:
- Starts with `/` (absolute local path)
- Starts with `s3://`
- Starts with `file://`

All other values (numbers, booleans, non-path strings) are treated as primitives.

**Empty outputs state:** Single row `text-center text-muted-foreground`: "No outputs recorded for this run."

### Inline Text Preview

**Trigger:** "Preview" link button (text link, `variant="link" size="sm"`) appears next to the Download button for File-type outputs. Only shown when the file path ends with a known text extension: `.txt`, `.log`, `.wdl`, `.json`, `.yaml`, `.yml`, `.tsv`, `.csv`.

**Expansion behavior:** Click toggles an expanded row below the file row (not a modal). The expanded area renders a `<pre>` block styled identically to `WDLSourceViewer` — `bg-muted/40 rounded p-4 text-xs font-mono overflow-x-auto`.

**Loading state while fetching:** Show `<div className="h-[80px] animate-pulse rounded bg-muted" />` inside the expanded area.

**Preview too large (server returns truncated content):** Show content followed by:
```
<p className="text-xs text-muted-foreground mt-2 border-t pt-2">
  Preview limited to 100 KB. Download the file to view the full content.
</p>
```

**Preview fetch error:** Show inside expanded area:
```
<p className="text-sm text-muted-foreground">
  Failed to load preview. Try downloading the file instead.
</p>
```

**Button label cycle:** "Preview" → (loading) → "Hide Preview" (when expanded). "Preview" again when collapsed.

---

### File Download

**Trigger:** "Download" button (`<Button size="sm" variant="default">`). Uses fetch+blob pattern (not apiClient).

**In-progress state:** Button shows `<Loader2 className="mr-2 h-4 w-4 animate-spin" />` and is `disabled`. Label: "Downloading…"

**Success:** No toast — browser download dialog handles feedback.

**Error:** `toast.error('Download failed. Please try again.')` using the existing sonner toast pattern.
