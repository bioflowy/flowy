**S3APIClient interface** (for mock injection in tests):
```go
type S3APIClient interface {
    PutObject(ctx context.Context, params *s3.PutObjectInput, optFns ...func(*s3.Options)) (*s3.PutObjectOutput, error)
    GetObject(ctx context.Context, params *s3.GetObjectInput, optFns ...func(*s3.Options)) (*s3.GetObjectOutput, error)
    ListObjectsV2(ctx context.Context, params *s3.ListObjectsV2Input, optFns ...func(*s3.Options)) (*s3.ListObjectsV2Output, error)
}
```

**S3Backend struct**:
```go
type S3Backend struct {
    bucket    string
    prefix    string
    threshold int64
    s3c       S3APIClient
    tm        TransferManagerUploader
}
```

Note: `TransferManagerUploader` should be an interface wrapping transfermanager.Client.Upload so tests can mock it:
```go
type TransferManagerUploader interface {
    Upload(ctx context.Context, input *s3.PutObjectInput, opts ...func(*transfermanager.Options)) (*transfermanager.UploadOutput, error)
}
```
IMPORTANT: Check the actual transfermanager API signature at implementation time via `go doc`. The method may be `UploadObject` not `Upload`, and the input type may be `transfermanager.UploadObjectInput` not `s3.PutObjectInput`. Adjust the interface accordingly.

**NewS3Backend(cfg *config.Config) (*S3Backend, error)** constructor:
- Use `awsconfig.LoadDefaultConfig(context.Background(), awsconfig.WithRegion(region))` — alias AWS config import as `awsconfig`
- If `sc.Region == ""`, use "us-east-1" as default for MinIO compatibility
- Create s3.Client with `s3.NewFromConfig(awsCfg, func(o *s3.Options) { ... })`
- When `sc.Endpoint != ""`: set `o.BaseEndpoint = aws.String(sc.Endpoint)` and `o.UsePathStyle = true` (required for MinIO S3-04)
- Create transfermanager.Client: `transfermanager.New(s3Client, func(o *transfermanager.Options) { o.MultipartUploadThreshold = sc.MultipartThreshold })`
- Return S3Backend with bucket, prefix, threshold, s3c, tm fields

**Also expose a test constructor** for injecting mock clients:
```go
func newS3BackendForTest(bucket, prefix string, threshold int64, s3c S3APIClient, tm TransferManagerUploader) *S3Backend
```

**Key helper — keyJoin(segments ...string) string**:
- Prepend prefix if non-empty
- Filter empty segments
- Join with "/" (never filepath.Join — S3 keys are not OS paths)

**Path helpers** (ignore baseDir parameter — S3 uses bucket+prefix):
- `RunInputsDir(baseDir, runID string) string` → keyJoin("runs", runID, "inputs")
- `RunOutputsDir(baseDir, runID string) string` → keyJoin("runs", runID, "outputs")
- `TaskDir(baseDir, runID, taskName string, shardIndex int) string` → keyJoin("runs", runID, "tasks", fmt.Sprintf("%s_%d", taskName, shardIndex)) — shard index in key prevents scatter collision (S3-05)

**Directory lifecycle** (no-ops — S3 creates keys on PutObject):
- `CreateRunDirs` → return nil
- `CreateTaskDirs` → return nil

**File I/O**:
- `UploadFile(path string, data []byte) error`: Use transfermanager for ALL uploads (it automatically dispatches PutObject for small, multipart for large). This simplifies the code — transfermanager handles the threshold check. Error wrap: `fmt.Errorf("s3: upload %s: %w", path, err)` (S3-01, S3-03)
- `DownloadFile(path string) ([]byte, error)`: Use s3c.GetObject, defer body.Close(), io.ReadAll(body). Map NoSuchKey to os.ErrNotExist via smithy error checking. Error wrap: `fmt.Errorf("s3: download %s: %w", path, err)` (S3-02)

**Streaming I/O**:
- `UploadFileStream(path string, r io.Reader) error`: Use transfermanager with r as Body
- `DownloadFileStream(path string, w io.Writer) error`: Use s3c.GetObject, io.Copy(w, body), defer body.Close()

**Directory I/O**:
- `UploadDirectory(path string, localSrc string) error`: Walk localSrc with filepath.WalkDir, for each file compute relative path, upload with UploadFile to key = path + "/" + relPath
- `DownloadDirectory(path string, localDst string) error`: Use s3c.ListObjectsV2 with prefix=path+"/", for each object download and write to localDst + "/" + relative key suffix. Handle pagination (IsTruncated + ContinuationToken).

**JSON I/O** (delegate to file I/O like LocalBackend does):
- `WriteJSON`: json.Marshal then UploadFile
- `ReadJSON`: DownloadFile then json.Unmarshal

**Error mapping**: For NoSuchKey errors from GetObject, use:
```go
var nsk *types.NoSuchKey
if errors.As(err, &nsk) {
    return nil, fmt.Errorf("s3: download %s: %w", path, os.ErrNotExist)
}
```
Import `"github.com/aws/aws-sdk-go-v2/service/s3/types"` for this.

**Import aliases**: Use `awsconfig "github.com/aws/aws-sdk-go-v2/config"` to avoid collision with project config package.
