<objective>
Extend the API contract and server to support API-based input/output delivery, replacing the file-based inputs.json/outputs.json handoff.

Purpose: The daemon needs inputs and WDL content embedded in TaskClaimResponse (not read from shared FS), and must report outputs via the result API (not write outputs.json to shared FS). This plan creates the server-side infrastructure that Plan 02 (daemon LED) consumes.

Output: Updated API types, SQLite migration, store methods, and server handlers that deliver inputs via claim API and persist outputs via result API.
</objective>
