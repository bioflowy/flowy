Implement the LED (Localize-Execute-Delocalize) pattern in the daemon for S3-backed task execution, with API-based input/output delivery for both local and S3 modes.

Purpose: This completes the daemon's ability to execute WDL tasks with S3 storage. S3 inputs are downloaded to a temporary staging directory, containers see only POSIX paths, outputs are uploaded back to S3, and results reported via API.

Output: Refactored daemon.go with LED functions and comprehensive unit tests.

  <name>Task 1: Implement LED functions and refactor executeTask</name>
  <files>internal/daemon/daemon.go</files>
  <behavior>
    - walkAndLocalize rewrites s3:// strings in nested map[string]any to local paths after downloading
    - walkAndLocalize passes through non-s3:// strings, booleans, numbers, arrays, maps unchanged
    - walkAndLocalize returns error on download failure with "localize: download s3://..." message
    - localizeInputs creates stageDir/inputs/, walks inputs, returns rewritten map and stageDir
    - delocalizeOutputs walks workDir, uploads each file via backend.UploadFileStream, returns map with s3:// URIs
    - delocalizeOutputs returns error on upload failure with "delocalize: upload ..." message
    - buildBackendFromClaim constructs S3Backend from claim's storage fields
    - reportResultWithOutputs sends TaskResultRequest with Outputs field populated
    - executeTask in S3 mode: reads inputs from claim.Inputs, parses WDL from claim.WDLContent, runs LED
    - executeTask in local mode: reads inputs from claim.Inputs, parses WDL from claim.WDLContent, no LED (existing flow but with API inputs)
    - stageDir cleaned up on success, preserved on delocalize failure, cleaned up on localize/run failure
  </behavior>
  <action>
  Add the following private functions to daemon.go. Add necessary imports: `internal/storage`, `internal/config`, `strings`, `path/filepath` (already imported), `io`, `os`.

  1. **buildBackendFromClaim(claim *api.TaskClaimResponse) (storage.Backend, error)**:
     - Construct a `config.Config` with Storage fields from claim (Type, Bucket, Endpoint, Prefix)
     - Set `cfg.Storage.MultipartThreshold = 100 * 1024 * 1024` (100 MiB default)
     - Call `storage.NewS3Backend(cfg)` and return
     - Wrap errors: `fmt.Errorf("build backend: %w", err)`

  2. **walkAndLocalize(v any, backend storage.Backend, inputsDir string) (any, error)**:
     - Recursive type switch on `v`:
       - `string`: if `strings.HasPrefix(val, "s3://")`, call `ParseS3URI` to get bucket+key, call `backend.DownloadFile(key)` to get bytes, write to `filepath.Join(inputsDir, filepath.Base(key))` (use `os.WriteFile`), return the local path. On error: `fmt.Errorf("localize: download %s: %w", val, err)`
       - `[]any`: recurse each element
       - `map[string]any`: recurse each value
       - default (bool, float64, nil): return unchanged
     - IMPORTANT: Use `filepath.Base(key)` for local filename to avoid directory creation issues. If name collision possible within one task (unlikely for WDL), use key path with os.MkdirAll instead.

  3. **localizeInputs(inputs map[string]any, backend storage.Backend) (localizedInputs map[string]any, stageDir string, err error)**:
     - `stageDir, err = os.MkdirTemp("", "flowy-stage-")`
     - `inputsDir = filepath.Join(stageDir, "inputs")`
     - `os.MkdirAll(inputsDir, 0755)`
     - Call `walkAndLocalize(inputs, backend, inputsDir)` — type assert result to `map[string]any`
     - Return localized inputs, stageDir, nil
     - On error: `os.RemoveAll(stageDir)` before returning error

  4. **delocalizeOutputs(outputs map[string]values.Value, workDir string, claim *api.TaskClaimResponse, backend storage.Backend) (map[string]any, error)**:
     - Walk `workDir` via `filepath.WalkDir`
     - For each regular file: compute `rel, _ := filepath.Rel(workDir, filePath)`, convert to slash: `keyRel := filepath.ToSlash(rel)`
     - Construct S3 key: `s3Key := claim.StoragePrefix + "/runs/" + claim.RunID + "/tasks/" + claim.TaskName + "_" + strconv.Itoa(claim.ShardIndex) + "/" + keyRel` (use OutputsDir from claim if it's an S3 key prefix, or construct from claim fields)
     - Actually simplify: use `claim.OutputsDir + "/" + keyRel` as the S3 key (OutputsDir is already the task dir key prefix in S3 mode). Use `path.Join` NOT `filepath.Join` for S3 keys, or explicit string concat.
     - Open file, call `backend.UploadFileStream(s3Key, f)`, close file
     - On upload error: return `fmt.Errorf("delocalize: upload %s: %w", s3Key, err)` immediately (fail on first error per user decision)
     - Build `localToS3` map: `localPath -> s3://bucket/key`
     - After walk: convert `outputs map[string]values.Value` to JSON via `values.ValuesToJSON(outputs)`, then walk the JSON map to rewrite any local file paths using the `localToS3` mapping
     - Return the rewritten JSON outputs map

  5. **rewriteOutputPaths(v any, localToS3 map[string]string) any**:
     - Recursive type switch: if string and exists in localToS3, replace with s3:// URI
     - Recurse arrays and maps
     - Pass through other types

  6. **(d *Daemon) reportResultWithOutputs(ctx context.Context, taskID, state, errMsg string, outputs map[string]any)**:
     - Same as reportResult but marshals `api.TaskResultRequest{State: state, Error: errMsg, Outputs: outputs}`

  7. **Refactor executeTask**:
     - Both modes now read inputs from `claim.Inputs` (not inputs.json file)
     - Both modes parse WDL from `claim.WDLContent` via `parser.Parse("task.wdl", []byte(claim.WDLContent))`. If `claim.WDLContent` is empty, fall back to `parser.Parse(claim.WDLPath, nil)` for backward compat.
     - Remove `os.ReadFile(inputsPath)` and `json.Unmarshal` for inputs — use `claim.Inputs` directly
     - For S3 mode (`claim.StorageType == "s3"`):
       - `backend := buildBackendFromClaim(claim)`
       - `localizedInputs, stageDir, err := localizeInputs(claim.Inputs, backend)`
       - On localize error: report FAILED, return
       - Use `keepStage` flag with defer: `defer func() { if !keepStage { os.RemoveAll(stageDir) } }()`
       - `outputs, err := task.RunTask(taskCtx, astTask, localizedInputs, task.NewDockerRunner(), stageDir, "", structDefs)`
         - Note: execRoot is stageDir (container work dir), wdlDir is "" (no relative path resolution in S3 mode since all inputs are absolute staged paths)
       - On RunTask error: report FAILED, return (stageDir cleaned by defer)
       - `jsonOutputs, err := delocalizeOutputs(outputs, stageDir, claim, backend)`
       - On delocalize error: set `keepStage = true`, report FAILED, return
       - On success: reportResultWithOutputs with COMPLETED + jsonOutputs, stageDir cleaned by defer
     - For local mode:
       - Use `claim.Inputs` directly as jsonInputs (they arrive as `map[string]interface{}` from JSON)
       - `outputs, err := task.RunTask(...)` with existing execRoot (claim.OutputsDir) and wdlDir
       - Serialize outputs and write outputs.json (keep existing behavior for local file reads)
       - Also call reportResultWithOutputs with the serialized outputs (so server can store them)
       - reportResult for COMPLETED (existing behavior, keeps backward compat)

  IMPORTANT anti-patterns to avoid:
  - Do NOT use `filepath.Join` for S3 key construction — use string concat with "/"
  - Do NOT clean stageDir on delocalize failure — set keepStage = true
  - Do NOT pass full s3:// URI to backend.DownloadFile — extract key via ParseS3URI first
