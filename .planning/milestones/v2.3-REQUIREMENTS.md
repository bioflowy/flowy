# Requirements: flowy v2.3 Managed File Labels & UX

**Defined:** 2026-04-19
**Core Value:** WDL 1.2で記述されたワークフローをDockerコンテナ上で正確に実行できること

## v2.3 Requirements

### Label Templates

- [x] **LABEL-01**: Workflow outputs can define a managed-file label template via `parameter_meta { output_name: { label: "..." } }`
- [x] **LABEL-02**: Label templates support `${var}`, `${var%suffix}`, `${var%%suffix}`, `${var#prefix}`, and `${var##prefix}` against workflow input string values
- [x] **LABEL-03**: Invalid, unsupported, or missing-variable label templates never invoke a shell and never fail workflow completion; the system falls back to a safe default label

### File Library UX

- [x] **FILEUX-01**: User can search/filter managed files in the Files tab by label, file type, and path
- [x] **FILEUX-02**: User can see whether a managed file came from workflow output or manual import, and can open the originating run when available
- [x] **FILEUX-03**: Managed file picker in workflow execution shows the file label prominently while still exposing the underlying path

## Outcomes

- All 6 milestone requirements shipped in phases 41-43.
- Validation evidence was recorded in `.planning/phases/41-label-template-engine/41-VERIFICATION.md`, `.planning/phases/42-file-provenance-metadata/42-VERIFICATION.md`, `.planning/phases/43-search-and-picker-label-polish/43-VERIFICATION.md`, and `docs/v2.3-verification-guide.md`.
- The milestone audit concluded `tech_debt`, not `gaps_found`: the product is complete, but some planning traceability artifacts were normalized only at closeout.

## Future Requirements

- Manual label editing for imported files
- Pagination and bulk actions for very large file libraries
- Wider shell-compatibility beyond the supported prefix/suffix trimming operators

## Out of Scope

| Feature | Reason |
|---------|--------|
| Executing a real shell or subprocess for label evaluation | Security boundary; evaluator must stay pure Go |
| Full POSIX shell parameter expansion compatibility | Too broad for this milestone; only the documented operators are needed |
| User-editable label templates from the browser | WDL-driven output labeling is the immediate need |
| Pagination in the Files tab | Search/filter is sufficient for the expected near-term library sizes |
