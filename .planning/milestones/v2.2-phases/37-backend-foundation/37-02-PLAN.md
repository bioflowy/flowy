# Plan 37-02: Backend.Stat and S3APIClient.HeadObject

## Goal

Add the `Stat(path string) (int64, error)` method to the `Backend` interface, implement it on `LocalBackend` (via `os.Stat`) and `S3Backend` (via `HeadObject`), extend `S3APIClient` with `HeadObject`, and update the mock in tests. After this plan, any caller can get the byte size of a storage object regardless of backend.

**Step 4 -- Implement S3Backend.Stat** (per D-14):

In `internal/storage/s3.go`, add:

```go
// Stat returns the size in bytes of the S3 object at the given key.
// Uses HeadObject internally -- does not download the object body.
func (b *S3Backend) Stat(path string) (int64, error) {
    out, err := b.s3c.HeadObject(context.Background(), &s3.HeadObjectInput{
        Bucket: aws.String(b.bucket),
        Key:    aws.String(path),
    })
    if err != nil {
        return 0, fmt.Errorf("s3: stat %s: %w", path, err)
    }
    if out.ContentLength == nil {
        return 0, nil
    }
    return *out.ContentLength, nil
}
```

CRITICAL: nil-check `out.ContentLength` before dereferencing -- AWS SDK v2 uses `*int64`.
