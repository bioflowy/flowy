# Plan 39-01: Atomic Workflow Completion Registration

**Phase:** 39 - Workflow Completion Hook and Type Annotation
**Status:** Completed

## Objective

Move successful workflow completion onto `CompleteRun(...)` so output JSON persistence, state transition, and managed-file inserts happen inside one SQLite transaction.

## Implementation Outline

1. Marshal workflow outputs once using the existing `workflowName.outputName` JSON contract.
2. Walk declared workflow outputs instead of inferring file-ness from raw JSON strings.
3. Flatten `File`, `Directory`, `Array[File]`, and `Array[Directory]` values into managed-file candidates.
4. Deduplicate duplicate paths within one completion event before calling `CompleteRun(...)`.
5. Preserve non-fatal `outputs.json` file emission and provenance timestamp updates after DB completion succeeds.

## Verification Targets

- Managed file registration happens only on successful workflow completion.
- A completion-time registration failure leaves the run out of `COMPLETED`.
- Existing run outputs JSON stays backward compatible.
