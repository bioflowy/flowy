# Plan 40-02: Managed File Picker in RunWorkflowDialog

**Phase:** 40 - UI - Files Tab and File Picker
**Status:** Completed

## Objective

Replace plain file-path-only workflow launch UX with a managed-file picker that still allows manual path fallback.

## Implementation Outline

1. Extend registry input responses with `file_type`.
2. Load project managed files in `RunWorkflowDialog`.
3. Render a picker for `File` inputs and filter it by `file_type` when present.
4. Keep the existing text input so manual paths still work.
5. Add tests for picker presence and filtering guidance.
